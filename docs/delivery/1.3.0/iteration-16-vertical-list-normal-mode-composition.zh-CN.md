# 迭代 16：纵向列表普通模式构图

> 适用版本：[Avenor Launcher 1.3.0 交付](delivery.zh-CN.md)。状态与实际证据只属于 `delivery.zh-CN.md`；本契约不授权实现或 Git／发布操作。

## 目标

在普通 Home 中把统一纵向收藏呈现为一个全宽或两个等宽、尺寸和滚动均相互独立的列表，不暴露编辑行为。

## 产品与版本引用

- [1.3.0 交付](delivery.zh-CN.md)
- [Home](../../product/surfaces/home.zh-CN.md)、[导航](../../product/navigation.zh-CN.md)、[设计基础](../../product/design-foundations.zh-CN.md)、[验证指南](../../validation.zh-CN.md)

## 可观察结果

普通 Home 准确呈现统一聚合中的零、一个或两个列表；每个列表使用自身大／中／小尺寸，能够启动应用，并仅在自身内容溢出时滚动。

## 纳入工作

- 以平等列表构图替代固定主／伴呈现；一个列表全宽，两个列表按契约间距等宽。
- 应用各自尺寸、无障碍语义、独立内容范围和同进程有意义纵向位置；进程重建回到起点。
- 在完整收藏构图上仅呈现一次 Loading、不可读 Error/Retry 和有效空状态。
- 保留启动、长按面板、禁用身份、badge、清单协调和普通模式 Home–Drawer 行为。

## 排除工作

不包含编辑模式、列表控件、临时列表、目标化 Drawer 新增、收藏栏、新拖动或导航阈值变化。

## 技术改动区域

普通 Home 构图、布局与滚动状态、条目呈现、无障碍、加载／错误／空状态及 UI 测试。

## 依赖与顺序

依赖已接受的迭代 15，并为迭代 17 建立普通模式界面。

## 迁移与兼容影响

不选择额外格式迁移；迁移及新写入状态必须一致呈现，并保留未被本契约改变的 `1.2.0` 导航和启动基线。

## 安全、隐私、权限与许可影响

不选择新权限、数据类别、网络、依赖或许可影响。

## 风险与未决事项

独立滚动可能破坏 Home–Drawer 边界交接；尺寸与字体缩放组合可能造成裁切或无效触控目标。实现架构由开发角色负责。

## 验收条件

- 零列表显示契约空状态；一个列表全宽；两个列表等宽。
- 各列表使用自身尺寸，仅在溢出时独立滚动，并保留启动、长按、badge、禁用、身份、排版和触控行为。
- 同进程往返保留有意义位置；进程重建回到起点。
- Loading、不可读状态、Retry 和清单变化不重复构图或破坏数据；Home–Drawer 手势在适用边界保持连续。

## 验证要求

建议覆盖零／一／二列表、全部尺寸组合、溢出、布局方向、字体缩放、同进程返回、进程重建、清单变化、Loading/Error/Retry、启动和导航交接。

## 相关决定与技术评估

不选择新决定；仅当证据要求重大布局、导航或状态所有权变化时上报。

## 作者指示的契约修订

2026-08-24，作者接受保留本迭代中已实现、且已通过设备基本验收的编辑会话拖动兼容行为，使当前 work 分支可以在不回退已验收行为的情况下完成。本次修订将编辑模式和新拖动行为从原排除边界调整为兼容性工作；普通模式构图仍是本迭代的主要交付结果。该修订要求完整聚合持久化，包括已有容器 ID、列表尺寸和收藏栏，并不新增列表控件、新列表创建、收藏栏管理或新的拖动语义。
