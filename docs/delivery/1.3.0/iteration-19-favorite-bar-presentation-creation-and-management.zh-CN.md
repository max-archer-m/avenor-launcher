# 迭代 19：收藏栏呈现、创建和管理

> 适用版本：[Avenor Launcher 1.3.0 交付](delivery.zh-CN.md)。状态与实际证据只属于 `delivery.zh-CN.md`；本契约不授权实现或 Git／发布操作。

## 目标

在纵向列表下交付收藏栏完整生命周期，包括呈现、目标化创建、本地管理、恢复和失败处理，但尚不加入跨容器应用移动。

## 产品与版本引用

- [1.3.0 交付](delivery.zh-CN.md)
- [Home](../../product/surfaces/home.zh-CN.md)、[Drawer](../../product/surfaces/drawer.zh-CN.md)、[导航](../../product/navigation.zh-CN.md)、[设计基础](../../product/design-foundations.zh-CN.md)

## 可观察结果

普通 Home 按需呈现最多五条无标题固定中等高度横向收藏栏，条目随短名称收窄且不超过契约最大宽度；编辑模式显示按目标区分的纯文本新增操作和紧凑的共享纵向列表控制栏，并允许创建收藏栏、向已有目标新增、删除应用或整栏、整栏排序、同栏交换、滚动溢出及使用契约 Undo。

## 纳入工作

- 在收藏列表区下呈现零至五条高 `56dp` 的收藏栏，并采用共享 Home 几何：在 `safeDrawing` 内统一设置 `8dp` 内容 padding，相邻模块间距为 `8dp`，收藏栏容器和条目均不增加额外 padding。收藏列表区和次级收藏区使用完整的已设置 padding 的 Home 内容宽度，而不是未经 padding 的安全宽度。每个固定中等高度条目由 `8dp` start 间距、`40dp` 图标、`8dp` 图标名称间距、最多实测 `64dp` 宽的名称和 `8dp` trailing 间距按内容测量，最大宽度为 `128dp`；短名称使条目收窄，长名称末尾省略。应用拖动柄继续使用贴合物理右侧边缘、宽 `40dp`、占满条目高度且没有 end margin 的热区。普通模式与编辑模式保持计算后的条目宽度和这些边界；编辑表面、边界和固定控制轨不再增加外侧缩进，编辑控件可以使名称更早省略。其余溢出淡化、启动、长按、身份、badge 和无障碍行为保持契约规定。
- 将共享纵向列表编辑控制栏优化为已确认的紧凑呈现：`40dp` 控制栏、内部 `36dp` 整体表面、之后的 `4dp` 内容间距、物理左／中／右 `36dp × 40dp` 热区、带 `20dp` 白色 X 的 `32dp` 实色 error 红色删除样式，以及 `20dp` 排序图形；不增加推测性的未来控件位置。
- 保留同进程横向位置，进程重建回到起点；应用 Drawer 捕获恢复与目标最小揭示。
- 将已有／临时收藏栏目标接入迭代 18，多选至少一个有效身份后才创建。
- 实现固定编辑轨、删除、条件整栏排序及适用的纯文本新增操作：已有列表和收藏栏使用`＋ 添加应用`，临时列表和临时收藏栏明确其将创建的容器。前置加号使用文本而非独立图标资源，完整本地化文案保持为一个至少 `48dp` 高的热区；容量允许时显示临时收藏栏。
- 实现应用删除、同栏交换、整栏删除／排序及最后一项消失后的自动删除。
- 对应用和整栏应用最新 Undo、容量保留及冲突成功新增失效；不得超过五条。

## 排除工作

不包含标题／命名／重命名、可选尺寸、可配置上限、跨容器插入／交换、应用拖动自动滚动、Drawer 搜索或通用 Undo 历史。

## 技术改动区域

次级收藏布局与条目测量、横向滚动、收藏栏控件、共享新增操作呈现、纵向列表控制栏呈现、临时创建、目标化 Drawer 复用、同栏交换、整栏排序、容量／Undo、无障碍和测试。

## 依赖与顺序

依赖迭代 18、17 和 15，并为迭代 20 建立全部容器类型。

## 迁移与兼容影响

不选择额外迁移。收藏栏是新的统一目标；有意义滚动位置是临时 UI 状态，成员和顺序持久化；不持久化空栏。

## 安全、隐私、权限与许可影响

不选择新权限、网络、数据类别、外部服务、依赖或许可影响。

## 风险与未决事项

五个横向状态可能与编辑和 Drawer 恢复冲突；固定轨不得改变持久化条目几何；Undo 容量、临时创建、空栏清理和清单协调需要单一容量所有者。

## 验收条件

- 零栏不占普通模式高度；一至五栏在 `safeDrawing` 内使用统一 `8dp` Home 内容 padding 及由此形成的完整内容宽度，并遵循相邻模块间距 `8dp`、收藏栏高度 `56dp`、容器与条目不增加额外 padding、应用拖动柄热区几何、条目几何、溢出、启动和长按行为；编辑模式不得再增加缩进。
- 基础信息几何通过明确的叠加关系保持原有最终安全边缘距离：Home 的 `8dp` 内容 padding 加各信息行的 `8dp` top/start/end margin，使其最终距适用安全边缘 `16dp`；日期文字再增加 `8dp` start 内缩，最终距安全 start 边缘 `24dp`，但完整行热区仍位于 `16dp` 边界。
- 每个收藏栏应用条目按照契约 `8dp + 40dp + 8dp + 名称 + 8dp` 构成按内容测量，名称渲染宽度最多为 `64dp`，条目总宽度最多为 `128dp`；短名称使条目收窄，长名称末尾省略，相邻条目保持 `8dp` 间距，编辑模式不得扩展条目。
- 持久化列表和已有收藏栏可见文案使用本地化的`＋ 添加应用`，临时列表和临时收藏栏的可见文案明确其将创建的容器。前置加号使用文本而非独立图标资源；完整文案是一个高度至少为 `48dp` 的本地化交互与无障碍目标，点击后记录正确目标且不改变既有创建语义。
- 每个持久化纵向列表使用契约规定的 `40dp` 控制栏、内部 `36dp` 整体表面、之后的 `4dp` 内容间距，以及物理左／中／右 `36dp × 40dp` 热区。删除使用带 `20dp` 白色 X 的 `32dp` 实色 error 红色圆角方形，排序使用 `20dp` 图形，尺寸和排序没有常驻独立背景；单列表隐藏排序但保留其位置。完整 `44dp` 预留只改变编辑模式应用视口，不改变收藏区外部高度或持久化状态。
- 同进程、编辑退出、系统 Home 和外部返回保留位置；进程重建回到起点。
- 已有／临时目标复用迭代 18，不复制状态机；仅以有效确认条目原子创建，绝不持久化空栏。
- 删除、同栏交换、整栏排序、空栏清理、失败恢复和 Undo 保持身份、成员和顺序。
- 一条栏隐藏排序，两条以上显示且不改变轨道几何；含 Undo 保留在内绝不超过五条。

## 验证要求

建议覆盖零至五栏、短名称与省略名称、溢出、横向恢复、四种本地化新增入口、紧凑纵向列表控件、单列表隐藏排序、已有／临时新增、取消与失败、一／多栏控件、同栏交换、删除／Undo、清单协调、字体、布局方向、无障碍和进程重建。

## 相关决定与技术评估

不选择新决定；重大状态、持久化、布局、手势或无障碍架构证据需要上报。
