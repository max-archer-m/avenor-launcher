# 迭代 14：Drawer 连续导航与锚点

> 适用版本：[Avenor Launcher 1.2.0 交付](delivery.zh-CN.md)。
>
> 本稳定契约定义选定交付范围。迭代状态、实际证据、commit、产物和结果仅归同级版本交付记录所有。本文件不授权生产实现或任何 Git、发布操作。

## 目标

交付 Home 与 Drawer 之间连续、可预测的直接操控和稳定的离散 Drawer AlphabetIndex 锚点导航，避免手势不连续、应用操作误触或与列表及收藏滚动冲突。

## 可观察结果

Home–Drawer 和 Drawer–Home 手势在拖动、反向、嵌套滚动交接、释放、完成、回弹、Back、取消和中断过程中遵循同一条连续的位置与透明度路径。Drawer 索引接触只选择可用的离散锚点，符合首次立即定位、后续平滑移动、最终目标稳定、触觉反馈和活跃 token 气泡的契约行为。

## 纳入工作

- 应用契约规定的 200dp 手势距离、1:1.5 Drawer 交互位移、120dp/60% 释放阈值、目标方向 fling、反向 fling、取消和收敛行为。
- 根据手势进度连续推导 Home 与 Drawer 透明度，并在反向、交接、释放、回弹和完成过程中保持连续。
- 允许 Home 上滑从每个契约规定的 Avenor 管理的普通模式区域进入，包括信息、收藏、空、Loading、Error 和 Retry 区域。
- 当触摸的溢出收藏组到达末端后，将剩余位移交给 Home–Drawer，且无需抬手或重做；两组独立仲裁。
- 当 Drawer 列表到达顶部边界时，将剩余向下位移交给 Drawer–Home，且无需抬手或重做。
- 保留编辑模式手势排除、指针所有权、多指安全、系统 inset 边界，以及对误触选择、长按或触觉操作的抑制。
- 对 `#`、非空 A–Z section 和 Settings 应用离散 Drawer AlphabetIndex 锚点，包括首次立即跳转、后续可替换的平滑滚动目标、最终锚点稳定、索引步进触觉反馈、活跃 token 气泡，以及需要时独立滚动的索引。
- 保持 Settings 索引锚点和唯一打开 Settings 的行之间的区别。
- 为所选行为新增或更新适度的测试与验证支持。

## 排除工作

- 修改当前手势距离、位移比例、透明度曲线、释放阈值或 Drawer 索引产品模型。
- 基于百分比的索引滚动、排队的锚点目标、从索引齿轮直接打开 Settings 或固定 section 标题。
- 除了集成已接受迭代 13 交互区域所需内容外，不变更主收藏/伴随收藏组合或持久化。
- TalkBack 专用替代索引交互、Drawer 网格或新导航界面。

## 技术变更区域

- 共享 Home–Drawer 过渡状态和端点收敛。
- 两个收藏组和 Drawer 应用列表的嵌套滚动协调。
- 指针识别、操作抑制、多指处理、取消和系统中断。
- Drawer 列表状态、section 锚点查找、AlphabetIndex 指针所有权、平滑滚动替换、气泡和触觉反馈。
- Compose/UI 测试、手势测试接缝及聚焦性能或帧连续性证据。

## 依赖与顺序

实现位于已接受的迭代 12 加载/返回行为和已接受的迭代 13 主收藏/伴随收藏 Home 交互区域之后。Loading、Error、Retry 和两个收藏组必须出现在最终手势仲裁验证中。仅当不掩盖必需的端到端导航结果时，Drawer 索引锚点才可以在本迭代内部独立开发。

## 迁移与兼容性影响

未选择已存收藏或应用数据迁移。既有有意义的 Drawer 锚点相对位置保留和同进程 Home 收藏组位置继续受当前契约约束。进程重建仍从 Home 开始，不恢复进行中的过渡。

## 安全、隐私、权限与许可证影响

未选择新增权限、网络访问、外部服务、依赖、用户数据类别或许可证影响。Android 系统手势和保留 inset 继续由平台管理。

## 风险与未决决定

- 如果过渡和列表状态未协调，嵌套滚动所有权可能产生跳动、位移丢失、重复操作或死区。
- 动画调优可能掩盖契约不一致，而未修复底层位置/进度模型。
- 如果取消语义错误，索引平滑滚动替换可能将过期目标排队，或停在错误的最终锚点。
- 性能目标需要在指定主要设备上获得证据；本契约不规定实现框架或无依据的数值帧耗时门槛。
- 重大导航或手势架构变化需要作者决定，并在适用时形成 ADR。

## 验收条件

- 目标方向拖动 100dp 时，在收敛前产生 50% 手势进度和 150dp Drawer 交互位移。
- 无合格目标方向 fling 时，在 119dp 释放返回起点，在 120dp 或以上释放完成到目标。
- 位置与透明度在拖动、反向、列表到过渡交接、释放、完成、回弹、取消和 Back 过程中保持连续。
- 在普通 Home 模式下，上滑可以从每个契约规定的 Avenor 管理区域开始，且不触发其选择或长按操作；编辑模式继续禁用 Home–Drawer 拖动。
- 溢出的触摸收藏组和 Drawer 应用列表分别在适用边界内，仅将未消费的剩余位移在同一指针序列中交出。
- 额外指针不会导致跳动、反转过渡、启动应用或开始另一条过渡。
- 首次接触可用索引 token 时立即跳到其锚点；进入另一个 token 时只选择一个可替换的平滑滚动目标，并产生一次索引步进触觉响应。
- 释放或取消后完成到最后选定锚点，活跃 token 气泡消失，索引不推导百分比位置，也不从齿轮打开 Settings。
- Loading 和 Error 状态隐藏索引，同时保留契约规定的 Home-to-Drawer 手势入口行为。

## 验证要求

建议的聚焦场景覆盖从时间、日期、每个收藏组、空、Loading、Error 和 Retry 开始手势；未溢出和溢出组；Drawer 列表非零偏移及顶部边界交接；119dp 和 120dp 释放；目标方向和反向 fling；方向反转；Back；取消；系统中断；多指；编辑模式；快速应用交互；每个可用索引 token；跨 token 移动；目标替换；索引取消；低高度索引滚动；Settings 锚点；应用清单锚点新增/移除；以及输入不变的重复刷新。

建议执行相关自动化检查、生成可安装 debug 构建，并由作者在指定主要设备上观察连续性和响应性。实际结果归 `delivery.md` 所有；本契约不记录任何检查已运行。
