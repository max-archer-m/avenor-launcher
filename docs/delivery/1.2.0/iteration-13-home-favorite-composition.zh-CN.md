# 迭代 13：Home 信息与可编辑收藏组合

> 适用版本：[Avenor Launcher 1.2.0 交付](delivery.zh-CN.md)。
>
> 本稳定契约定义选定交付范围。迭代状态、实际证据、commit、产物和结果仅归同级版本交付记录所有。本文件不授权生产实现或任何 Git、发布操作。

## 目标

交付契约规定的 Home 基础信息对齐和完整、可直接访问的主收藏/伴随收藏组合，包括独立滚动、顺序持久化以及组内和跨组编辑。

## 可观察结果

日期文本使用契约规定的逻辑 start 内缩，同时保留完整触摸目标。Home 按契约组合显示视觉上可区分的主收藏和伴随收藏；两组都可以启动且独立滚动。编辑模式支持立即持久化的组内排序、跨组移动和占用位置交换，不丢失、不重复或覆盖收藏。

## 纳入工作

- 对可见日期与星期文本应用契约规定的 `8dp` 逻辑 start 内缩，且不缩小完整的 `48dp` 可聚焦触摸目标。
- 在共享组合宽度中以约 55% 呈现主收藏、约 45% 呈现伴随收藏。
- 应用每组契约规定的图标、目标、字体、间距、空余空间和独立滚动行为。
- 从 Drawer 新增的收藏默认进入主收藏，不打开 Home 或编辑模式。
- 通过所选收藏的 Launcher 操作进入编辑模式，并保留契约规定的编辑表面和仅 Back 退出方式。
- 支持组内排序、跨组插入、占用位置交换、目标组预览、有效放置反馈、无效放置恢复和目标组边缘自动滚动。
- 每次完成排序、移动或交换后立即持久化。
- 保留身份、顺序、禁用/不可用行为、应用清单协调和共享加载/错误/Retry 组合。
- 为所选行为新增或更新适度的测试与验证支持。

## 排除工作

- Home–Drawer 过渡调优、连续嵌套滚动交接、释放阈值、收敛行为和 Drawer 索引锚点交互。
- 产品定义的收藏容量、自动分配到伴随收藏、自动排序、文件夹、撤销、导出、修复、重置、备份或恢复。
- 底部次要区域内容。
- 双击锁屏授权或构建集成变更。

## 技术变更区域

- Home 布局、语义、触摸目标和编辑模式呈现。
- 收藏领域状态、组归属、顺序、持久化序列化和迁移。
- 独立组滚动状态及拖放手势所有权。
- Drawer 新增收藏路径和应用清单驱动的收藏协调。
- Compose/UI 测试、持久化测试或测试接缝及聚焦设备旅程。

## 依赖与顺序

实现位于已接受的迭代 12 加载和返回语义之后。本迭代必须在迭代 14 最终确定覆盖两组收藏的 Home 手势仲裁前完成。日期对齐可以作为本迭代内的聚焦 commit 实现，但仍属于同一迭代验收结果。

## 迁移与兼容性影响

来自 `1.0.0` 和 `1.1.0` 的可读收藏必须保留可启动身份和既有顺序。没有伴随组归属的既有收藏按原顺序进入主收藏，除非实现证据要求其他经作者批准的迁移。迁移在适用时必须版本化且具备原子性。不可读或损坏状态不是空状态，不得迁移、修复、清除或覆盖。

不增加降级行为。已接受的 `1.2.0` 产物必须在发布治理和既有签名身份下支持原地升级。

## 安全、隐私、权限与许可证影响

未选择新增权限、网络访问、外部服务、依赖、用户数据类别或许可证影响。收藏组和顺序继续作为 Avenor 本地自有状态，受当前隐私和备份排除边界约束。

## 风险与未决决定

- 如果没有明确的指针所有权，跨组拖动、独立嵌套滚动和边缘自动滚动可能互相冲突。
- 如果迁移不具备原子性且不了解 profile，持久化格式变更可能造成破坏性丢失或错误身份映射。
- 当前产品契约选择可观察的 55/45 组合，但不规定具体 Compose 布局架构。
- 重大的持久化或手势架构变化需要作者决定，并在适用时形成 ADR。

## 验收条件

- 在两种布局方向下，日期与星期可见文本都具有契约规定的 `8dp` 逻辑 start 内缩，完整行仍是 `48dp` 可聚焦触摸目标。
- Home 按契约相对宽度、视觉层级、独立滚动位置和保留空余空间呈现主收藏与伴随收藏区域。
- 两组都可启动条目并暴露适用的长按操作。
- Drawer 新增项追加到主收藏，绝不静默分配到伴随收藏。
- 编辑模式支持组内排序、跨组插入、占用位置交换、有效目标预览、无效放置恢复和溢出组边缘自动滚动。
- 每次完成的变更只保存一次，并在适用的重新打开、进程重建或重启场景中保留。
- 从可读既有收藏状态升级时保留身份和顺序且不丢失或重复；不可读状态保持原样且禁用变更。
- 应用清单变化以及禁用或暂时不可用收藏遵循当前 Home 契约。

## 验证要求

建议的聚焦场景覆盖零收藏、仅主收藏、仅伴随收藏、两组都有、每组分别溢出、组内排序、双向移动、占用位置交换、无效放置、边缘自动滚动、Back 退出、进程重建、设备重启、可读升级、不可读持久化、安装/移除/禁用/重命名/clone/profile 变化、英文、中文、fallback locale、RTL 和相关字体缩放。

建议执行相关自动化检查、生成可安装 debug 构建，并由作者在指定主要设备上观察。实际结果归 `delivery.md` 所有；本契约不记录任何检查已运行。
