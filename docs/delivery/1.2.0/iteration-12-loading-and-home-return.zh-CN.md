# 迭代 12：加载与 Home 返回基础

> 适用版本：[Avenor Launcher 1.2.0 交付](delivery.zh-CN.md)。
>
> 本稳定契约定义选定交付范围。迭代状态、实际证据、commit、产物和结果仅归同级版本交付记录所有。本文件不授权生产实现或任何 Git、发布操作。

## 目标

建立可预测的应用数据加载和 Launcher 返回行为，使可用 Home 状态不会被不必要的阻塞式重复加载替换，并使系统 Home 或外部应用返回到达正确的 Avenor 界面。

## 可观察结果

冷启动和进程重建仍执行必需的初始读取。重新进入仍存活的 Avenor 进程或在其内部导航时，按产品契约要求复用有效状态。当 Avenor 是默认 Launcher 时，Android 系统 Home 操作从任意 Avenor 界面显示 Avenor Home；从普通外部应用同进程返回时显示 Home，不恢复瞬态界面，也不强制重新进行阻塞式初始读取。

## 纳入工作

- 识别并修正普通同进程界面导航或返回引起的收藏或应用清单重复加载。
- 区分冷进程启动、进程重建、同进程返回、显式 Retry、package/profile 变化和 Settings 相关系统状态变化。
- 对安装、移除、启用、禁用、重命名、克隆或受 profile 限定的可启动条目保留必需的刷新与协调。
- 独立于 Avenor Back 和 Drawer 过渡行为，落实契约规定的系统 Home 行为。
- 落实从 Home 或 Drawer 启动应用后的外部应用往返与同进程返回行为。
- 同进程返回时保留可用 Home 内容和有意义的收藏组位置；只重置导航契约排除的瞬态界面。
- 保持 Loading、Error、Retry 和不可读持久化行为符合当前 Home 与 Drawer 契约。

## 排除工作

- 主收藏/伴随收藏布局、迁移和编辑。
- Home 日期对齐。
- Home–Drawer 手势、透明度、收敛动画、嵌套滚动或索引锚点变更。
- 持续后台轮询、网络触发重载、云同步或推测性的通用缓存框架。

## 技术变更区域

- Launcher 生命周期与 Avenor 界面状态所有权。
- 收藏持久化及应用清单加载触发点。
- package/profile 更新协调。
- 外部应用启动返回处理和系统 Home 处理。
- Loading、错误、Retry 和进程重建测试或测试接缝。

## 依赖与顺序

已接受的 `1.1.0` 作者日用基线是进入基线。本迭代是当前规划的第一个 `1.2.0` 增量，并为迭代 13 和 14 建立状态行为。它不授权实施后续迭代。

## 迁移与兼容性影响

未选择收藏数据格式变更。既有可读收藏及顺序必须保持完整。不可读收藏状态必须原样保留，不得解释、修复、清除或覆盖为空状态。不得仅为避免重复加载而压制必需的 package 和 profile 更新。

## 安全、隐私、权限与许可证影响

未选择新增权限、网络访问、用户数据类别、外部服务、依赖或许可证影响。既有最小权限、profile、Private Space、备份排除和本地数据边界保持不变。

## 风险与未决决定

- 重复加载和帧阻塞的准确来源需要实现证据；本契约不假设特定架构。
- 如果误删必需的 package/profile 协调，生命周期去重可能产生过期清单。
- 在 Android 和 OEM 生命周期行为下，同进程返回和进程重建必须保持可区分。
- 状态所有权或持久化架构的重大变化需要作者决定，并在适用时形成 ADR。

## 验收条件

- 冷进程启动和进程重建执行必需的初始读取并从 Home 开始。
- 普通 Home、Drawer、Settings 和操作面板导航不启动冗余的阻塞式初始读取。
- 当 Avenor 是选定默认 Launcher 时，从 Drawer 和 Settings 执行 Android 系统 Home 操作会显示 Home，且不被当作 Back。
- 从普通外部应用同进程返回时显示 Home，不恢复 Drawer、Settings、操作面板、编辑模式或进行中过渡，也不以 Loading 替换可用 Home 内容。
- 同进程返回保留可读收藏状态及每组有意义的 Home 滚动位置。
- 显式 Retry 和确认的应用/profile 变化仍执行必需读取或协调。
- 加载或协调失败不清除可读或不可读的已存收藏，也不崩溃或形成导航死路。

## 验证要求

建议的聚焦场景包括冷启动、进程重建、Home–Drawer–Home、Settings–Back、从 Drawer 和 Settings 执行系统 Home、从 Home 和 Drawer 启动应用后同进程返回、外部应用往返期间进程死亡、显式 Retry，以及应用安装/移除/启用/禁用/重命名或 clone/profile 变化。在可行时记录加载触发观察。

建议执行相关自动化检查、生成可安装 debug 构建，并由作者在指定主要设备上观察。实际结果归 `delivery.md` 所有；本契约不记录任何检查已运行。
