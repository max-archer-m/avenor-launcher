# 迭代 11：呈现、兼容性与版本收尾

> 适用于 [Avenor Launcher 1.1.0](delivery.zh-CN.md)。本记录规划完成版本所需的有界实现清理与证据工作，不授权实现、签名、制品移动、commit、push、tag、GitHub Release 或分发。

## 状态

- 值：`Planned`
- 更新日期：2026-08-15
- 依据：作者已选择移除不必要的应用名称跑马灯，并为 `1.1.0` 设置专门测试出口；尚未授权生产实现或版本收尾。

## 目标

让应用名称呈现符合当前静态单行产品契约，移除过时的跑马灯行为，并建立证据证明完整的 `1.1.0` 已选路径是一份升级安全的作者日常使用基线。

## 可观察结果

Home 与 Drawer 的应用名称保持静止、单行，并在必要时使用末尾省略，不存在跑马灯开始、暂停、优先级或重新开始行为。获接受的 `1.1.0` APK 保留 `1.0.0` 可读收藏数据，在必需基线上完成迭代 7-10 的已选路径，并具备准确源码、构建、版本、签名类别、设备和已知缺口证据。

## 纳入工作

- 移除 Drawer 应用名称跑马灯，以及过时的公共计时、活动条目优先级、暂停、重新开始、过渡和测试状态。
- 确认 Home 主收藏和 Drawer 应用名称在纳入语言及代表性字体缩放下使用静态单行末尾省略呈现。
- 执行或收集 [delivery.zh-CN.md](delivery.zh-CN.md) 要求的版本级验证，包括升级、回归、离线、本地化、手势、身份/profile、Settings、双击锁屏和失败路径证据。
- 检查当前合并 manifest 和适用 Android 备份配置，包括 `android:allowBackup`、`android:dataExtractionRules`，以及受支持 API 范围的旧版或等效规则；记录证据，确认 Avenor 自有收藏持久化文件不会进入 Android 云备份或设备迁移备份。
- 确认准确 `applicationId`、`versionName`、下一个未分配的 `versionCode`、源码 commit、构建阶段、签名类别、设备/API/OEM 观察结果和可用 APK 身份。
- 记录所有失败、跳过、未知、不可用或范围外检查，并为遗留问题分配明确后续去向。
- 只依据观察证据和作者验收完成迭代 7-11 及版本完成结果。

## 排除工作

- 替代跑马灯、多行应用名称、用户可配置文字运动，或当前契约外的其他呈现能力。
- 伴收藏、跨组编辑、卸载操作、手动语言选择、更广 Settings、监控平台接入、公开分发、tag、里程碑或 GitHub Release。
- 把未执行的兼容性、政策、安全、隐私、许可证、性能或自动化检查声称为已通过。

## 技术影响面

Drawer 与公共应用名称呈现状态、过时跑马灯清理、聚焦 UI/状态测试、回归验证、升级安装、构建/版本身份、签名类别观察、APK 可追踪性和交付证据。在本迭代发现的重大问题应返回其所属迭代或明确授权的修正任务，不得隐藏在收尾工作中。

## 依赖和顺序

依赖已经完成并得到作者验收的迭代 7-10 及其可用证据。由于其清理和验证横跨已选产品路径，本迭代是版本收尾迭代；它不会在迭代 7-9 之间创建原本不存在的依赖。

## 迁移和兼容性影响

从已验收 `1.0.0` 直接升级时，必须保留全部可读收藏及其顺序，直到作者主动改变。移除跑马灯状态不得改变应用身份、排序、列表位置、选择、滚动、Home/Drawer 过渡或无障碍语义。不支持降级。

## 安全、隐私、权限和许可证影响

收尾工作核对所选作者日常使用基线要求记录的权限、服务、manifest、依赖、签名类别和隐私边界。它不单独授权新依赖、监控服务、发布签名身份、上传或专业结论。

## 风险和未决决定

- 纳入路径检查失败时必须修正，或返回作者明确决定范围/验收；不得为了完成版本而把失败重新标记为无害限制。
- 强制主要设备证据在作者或获明确授权的 Agent 执行前始终是版本完成门禁。建议的 API 31、额外 API 36/API 37 设备和 OEM/profile 证据可以按照版本规则记录为不可用。
- 当前 Android 备份配置尚未被评估为通过；开发角色必须确定准确工程配置并产生所需排除证据。
- 最终 `versionCode` 在获接受制品边界确认此前全部可追踪 APK 分配前保持暂定。

## 验证计划

在强制的作者指定主要物理设备上，版本出口覆盖：从已验收 `1.0.0` 升级；零/一/二/多个主收藏；编辑可见性、表面、排序、持久化、重启和失败；从 Home 与 Drawer 面向准确身份/profile 的应用快捷操作；Settings 导航、默认主屏幕状态刷新、本地内容、仓库与版本展示；双击锁屏披露、授权、手势排除、撤销和失败；滚动、更新和 Home/Drawer 过渡期间的静态应用名称；英文、简体中文和回退资源；离线核心路径；以及已验收 `1.0.0` 路径回归。出口还要求工程证据，确认 Android 备份配置会把 Avenor 自有收藏持久化文件排除在云备份和设备迁移之外。

API 31、另一台 API 36 或 API 37 物理设备以及额外 OEM/profile 覆盖属于建议证据。未执行时必须记录为 `Unknown`、`Not run` 或 `Unavailable`，其缺失本身不阻塞 `1.1.0`。执行后如果发现纳入路径失败，就必须解决或返回作者处置，不得因该环境属于建议证据而忽略。适用命令、环境、步骤和结果必须准确记录。
