## 版本契约边界

本交付记录保留 `1.1.0` 在获授权边界上选择的范围。当前产品契约可以在本版本规划或完成期间继续变化。当前产品契约后续发生的变化不会追溯扩大本版本的所选范围，也不会改变其完成结果。

记录完成结果时，该结果只适用于所选的 `1.1.0` 范围、其验收标准、`Author daily-use baseline` 交付级别以及本版本保留的证据。

## 版本意图

`1.1.0` 在已验收的 `1.0.0` 日常使用基线上增加四个由用户控制的工具增量：全宽主收藏编辑与排序、从两个应用上下文调用平台应用快捷操作、基础 Settings 界面，以及包含授权与披露闭环的可选双击锁屏。最后一个收尾增量移除不必要的应用名称跑马灯并验证版本已选路径。伴收藏和完整双组编辑能力未被本版本选择。本边界说明不决定它们未来的产品状态。

本版本仍属于 V1 固定展示层。迭代记录只表达真实交付依赖，不把范围绑定到终端、贡献者、分支、预测日期或永久开发线。当前执行计划仍可只使用一条活动任务线，而不改变这些契约。

## 纳入范围和用户路径

作者可以编辑并调整至少两个全宽 Home 主收藏并保留所选主收藏顺序；从 Home 或 Drawer 打开的共用操作面板调用平台提供的应用快捷操作；从 Drawer 打开 Settings，查看或使用默认主屏幕状态、Avenor License、项目仓库和版本信息；阅读已确认的本地 Privacy 与显著披露内容；并可选择通过 Android 系统无障碍设置授权双击锁屏。应用名称保持静止，必要时使用末尾省略。

全部已验收的 `1.0.0` Home、Drawer、启动、操作面板和收藏行为继续作为兼容基线纳入范围。

## 排除项

- 伴收藏展示、归属、持久化与编辑，包括跨组移动和交换。
- 超出当前产品和双击锁屏披露边界所需已确认本地声明的 Privacy 内容。
- Third-party License 展示，等待权威依赖清单和适用审核。
- 手动语言选择、诊断、更新检查、备份、云能力或更广 Settings 功能。
- `1.1.0` 不选择快捷操作 overflow 交互；本文不决定其未来的产品状态。
- 公开分发、tag、里程碑或 GitHub Release。
- 多分支、并行任务线或多人协作工作流变更。

## 技术方向和风险

实现细节由开发负责。在依赖相关能力前，适用迭代必须验证面向所选可启动身份和 profile 的平台快捷操作发现与调用、排序写入的持久化兼容性、默认主屏幕系统设置目标，以及最小无障碍服务声明、状态检测、披露和锁屏操作行为。作者批准的 Privacy 与显著披露正文已经由所链接的当前产品契约定义；启用验收仍要求实现与其一致，并满足其余技术和设备门禁。

技术评估与迭代 11 收尾已检查 Android 备份配置，包括 manifest、`android:allowBackup` 和 `android:dataExtractionRules`。当前工程和合并 manifest 证据确认 Avenor 自有收藏持久化文件已排除在 Android 云备份和设备迁移备份之外。实际 Android 备份传输未执行，但不阻塞本次作者日常使用基线。

改变身份、持久化兼容性、权限、架构或产品验收的重大结论需要作者决定，并在适用时形成 ADR。迭代 10 可以在 AccessibilityService ADR 建立前先执行聚焦技术验证，但在证据支持其边界并由必需 ADR 记录之前，产生的服务不得集成到版本主线。普通 UI 状态、平台适配器和测试接缝仍属于代码层决定。

## 验证

版本必需环境为一台作者指定的主要物理设备。版本完成要求：

- 一个使用已选标识的可安装 APK；
- 成功升级或安装，且不会意外丢失可读取的 `1.0.0` 收藏；
- 当前 Android 备份配置的证据，确认 Avenor 自有收藏持久化文件不会进入 Android 云备份或设备迁移备份；
- 保留全宽主收藏呈现，不存在伴收藏区域、占位或预留宽度；
- 应用名称保持静态单行，不残留跑马灯行为；
- 双击锁屏用于启用验收前，已经确认本地 Privacy 与显著披露内容；
- 作者在该设备上验收完整纳入路径；
- 不存在已知的纳入路径崩溃、ANR、破坏性收藏状态错误、错误 profile 快捷操作调用或不可用 Settings 跳转；
- 由作者处置影响已选日常使用基线的跳过、未知、失败或不可用检查。

指定主要物理设备是本交付级别唯一强制的设备环境。聚焦自动化检查、API 31、另一台 API 36 或 API 37 物理设备、额外 OEM/profile 覆盖、快捷操作变体、进程重启、locale 切换和无可用处理器路径均为建议证据。未执行的建议检查必须记录为 `Unknown`、`Not run` 或 `Unavailable`，其本身不阻塞 `1.1.0` 完成。建议检查一旦执行并发现纳入路径失败，就必须解决或明确返回作者处置；不得因它原本属于建议证据而忽略失败。

## 已知限制和遗留问题

- 平台快捷操作的可用性与展示取决于 Android 对所选应用和 profile 暴露的内容。
- 双击锁屏在用户明确启用用途受限的服务前保持关闭；OEM 设置和服务行为需要设备证据，未来商店分发需要重新进行政策审核。
- 未定义专用快捷操作 overflow 交互。
- 超出 `1.1.0` 已确认本地声明的 Privacy 内容和第三方许可证展示仍按上述说明排除在本版本外。
- 本交付级别不要求的更广兼容性与正式发布证据，在实际执行前保持未知。

## 完成结果

`1.1.0` 已完成所选择的 `Author daily-use baseline` 范围。迭代 7-11 均为 `Completed`。获验收构建使用 `applicationId` `com.avenor.launcher`、`versionName` `1.1.0` 和 `versionCode` `2`。获验收的 `1.1.0` 构建由源码 commit `7ae840bcf3c35a1bed340d4ff99ffcfbaad86ab9` 表示。

项目作者使用由作者本地 keystore 文件签名的 `debug` 构建，在运行 Android 16 和 One UI 8.5 的 Samsung Galaxy S23 Ultra 上完成基本验收；使用个人 profile，设备同时存在部分应用分身。获验收路径包括主收藏编辑与排序、应用快捷操作、Settings、可选双击锁屏、静态应用名称呈现以及修正后的 Home→Drawer 手势路径。

升级验证使用 commit `96a9e68a21c7c55844deb06b2e4ca7284788d091` 对应的已验收 `1.0.0` 基线。原位覆盖升级到 `1.1.0` 正常完成，多条收藏及其顺序保持不变。工程配置和合并 manifest 证据确认已选备份排除边界。额外设备/API/OEM 覆盖和实际 Android 备份传输未执行，不阻塞本次经作者验收的日常使用基线。

本完成结果不声称已执行 push、tag、GitHub Release、上传或分发；这些动作仍分别需要授权。
