# 迭代 8：应用快捷操作

> 适用于 [Avenor Launcher 1.1.0](delivery.zh-CN.md)。本记录规划一个产品增量，不授权实现或 Git/远程操作。

## 状态

- 值：`Planned`
- 更新日期：2026-08-13
- 依据：作者已为 `1.1.0` 选择应用快捷操作；尚未授权生产实现。

## 目标

从 Home 和 Drawer 的共用操作面板展示并调用平台提供的应用快捷操作，同时保留所选应用身份和来源界面状态。

## 产品与版本引用

- [1.1.0 交付](delivery.zh-CN.md)
- [应用操作面板](../../product/surfaces/app-action-sheet.zh-CN.md)
- [Home](../../product/surfaces/home.zh-CN.md)
- [Drawer](../../product/surfaces/drawer.zh-CN.md)

## 可观察结果

在 Home 或 Drawer 长按符合条件的应用，会在应用身份与启动器操作之间展示平台提供的快捷操作；选择后调用匹配的平台操作并关闭面板。没有已暴露快捷操作的应用继续使用现有紧凑面板。

## 纳入工作

- 面向 Avenor 可见的准确所选可启动条目和 profile 发现快捷操作。
- 共用快捷操作区域展示、图标与标签、条件分隔线、调用、关闭和来源位置保留。
- Home 与 Drawer 使用相同快捷操作能力。
- 在当前无专用 overflow 契约下安全展示平台返回数量。

## 排除工作

- 创建、固定、编辑、排名、推荐或持久化 Avenor 自有快捷操作。
- 新 overflow 产品交互或快捷操作专用成功/失败 UI。
- 卸载行为变更、Settings、双击锁屏或 Private Space 访问。

## 技术变更面

平台快捷操作适配器、可启动/profile 身份映射、共用操作面板状态与布局、调用边界、资源和聚焦测试。受支持平台 API 和过滤规则必须依据当前工程约束验证，不从 `1.0.0` 技术评估文字推断。

## 依赖和顺序

依赖已验收的 `1.0.0` 共用操作面板和稳定的可启动项/profile 身份模型。本迭代与迭代 7、迭代 9 之间不存在功能依赖。

## 迁移和兼容性影响

不计划存储数据迁移。现有收藏、Drawer 排序、面板启动器操作和来源恢复必须保持兼容。快捷操作可用性可因应用、profile、设备和平台状态合理不同。

## 安全、隐私、权限和许可证影响

仅使用当前最小权限边界内平台暴露的快捷能力。任何新 manifest 权限、可见性扩张、敏感 profile 访问或依赖都必须在采用前明确审核。

## 风险和未决决定

- 平台可能不暴露快捷操作，或为主应用、分身和工作 profile 暴露不同集合。
- 调用绝不能面向错误 profile 或应用身份。
- 异常多快捷操作没有专用 overflow 设计；实现必须在不发明该交互的情况下保持安全。
- 产品有意不提供快捷操作专用失败 UI；重大可用性失败必须返回产品审核。

## 验证计划

建议场景包括 Home 和 Drawer 来源；零/一/多个快捷操作；主应用及可用分身/工作 profile；正确标签/图标；调用；Back 和 scrim 关闭；不可用或变化的快捷状态；较大数量；保留 Drawer 锚点、Home 顺序和启动器操作。除非提升，否则不是自动门禁。

## 验收证据

尚无实现证据。执行时记录提供快捷操作的应用、所选身份/profile、来源、设备/API、调用结果、状态保留、失败和跳过场景。
