# 迭代 31：编辑坞、Drawer 背景与面板阴影重构

## 目标

按已被接受的产品契约完整交付四项作者已接受的重构：Home 编辑坞移至安全内容顶部并采用纯表现层的面板槽位交换动画；Drawer 背景重构为带百分比读数的连续背景不透明度滑杆，并移除开关、模糊与回退；共享样式设置面板的边缘边框；收藏多选呈现重构为统一覆盖角标。

## 可观察结果

在主设备上，Home 编辑模式在两种面板状态下都把固定编辑坞行显示在安全内容顶部；展开与收起样式设置面板时，信息区与面板按一次槽位交换动画过渡，不遮挡列表。Drawer 显示设置的背景组呈现一个连续百分比滑杆及其固定宽度百分比读数，具备契约规定的默认值、实时预览、抬起提交与中断回退行为。Home 与 Drawer 的样式设置面板都渲染契约的边缘边框。收藏多选不再有前置指示区，选中行呈现缩放、描边与覆盖角标，未选中行与被停用行保持朴素。

## 纳入工作

- 位于基础信息区与收藏主列表上方的固定顶部编辑坞行：坞行与右侧切换控件在收起与展开两态保持同一位置与交互热区，仅方向图标与指示文案变化；切换从不滚动主列表，也不改变其逻辑滚动位置。
- `48dp` 坞高与 `48dp x 48dp` 控件热区，移除先前的坞高度特例。
- 面板槽位交换动画：展开时信息区高度收敛到零、面板生长到内容高度、主列表连续吸收差值；面板保持不遮挡、非模态、无遮罩，并具备纯表现层语义——状态立即提交、中断收敛到终态、重复切换重定向、减少动态效果时跳过、动画期间按当前可见边界命中测试。
- Drawer 背景组改为一个连续背景不透明度滑杆及其固定宽度百分比读数：所选百分比把 `darkSurfaceBaseColor` 按该不透明度合成到壁纸上，`0` 呈现壁纸清晰，`100` 呈现纯色表面，新配置默认 `50`。
- 连续 `0`–`100` 滑杆模型：整数百分比刻度（暂定接受）、平台标准连续 progress 呈现且无刻度点、活动轨道与拖动柄使用 `primaryTextColor`、非活动轨道使用 `secondaryTextColor`、按 `100%` 计量的读数固定宽度预留，以及无障碍百分比播报与步长 `1` 的范围操作。
- 移除平台跨窗口模糊、可用性检测与透明表现回退：背景在所有设备上都是唯一的透明度处理，表现规范定义的文字与图标阴影在所有百分比下保持生效。
- 滑杆拖动行为：连续预览不持久化，指针抬起时恰好提交一次显示设置保存，抬起前被打断立即回退到持久化状态；拖动期间每跨过一个整数百分比产生一次短促刻度震动；"仅一个未决保存"规则不变。
- 背景不透明度百分比的持久化与版本化迁移：缺失字段按契约默认规则收敛，先前的透明／磨砂玻璃模式选择不做映射，百分比进入备份文件内容与本地数据枚举。
- 共享读数+滑杆行几何，采用 primaryTextColor 强调色与契约的控制间距。
- Home 与 Drawer 面板上的样式设置面板边缘边框：一圈 `1dp` 的 `#6E6E73` 边框，沿面板圆角绘制，使用作者已接受的交付数值。
- Drawer 样式设置面板打开与关闭使用一次高度属性动画：高度从 `0` 生长至内容高度并原路收回，基于共享短时长属性动画 token。
- 收藏多选呈现重构：多选行复用普通清单的每行数量网格与排布且布局不变；可用的未选中行不显示选择指示；选中单元格采用约 `90%` 的纯视觉缩放变换（布局边界不变）、完整的 `2dp` `primaryTextColor` 描边与 `12dp` 圆角，以及一个按呈现规范样式定义的左上角非交互覆盖顺序角标。
- 被停用的已收藏行去除角标、描边与缩放；选择模型的选择切换、顺序编号与重编号、确认与保存语义、无障碍语义保持不变。
- 新增或变更的用户可见文本的英文与简体中文字符串，包括背景不透明度滑杆标签与百分比格式。
- 聚焦测试源：坞位置与热区稳定性、动画中断与重定向、滑杆映射与抬起提交、中断回退、旧背景值迁移、边框实现。

## 风险与未决决策

- 低背景百分比以可读性换取壁纸可见性，属于用户自选权衡；固定前景投影必须在所有百分比下保持契约数值，所选值以作者设备验收为准。
- 旧枚举背景配置的迁移不得丢失无关显示设置，也不得触发失败路径；旧模式选择本身按契约不做映射。
- 槽位交换动画必须在中断与重定向期间保持命中测试、滚动位置与拖动收藏目的地几何与已提交状态一致。
- 滑杆抬起提交的保存必须遵守"仅一个未决保存"规则，在该保存收敛前不能开始第二次变更。
- 边框数值为作者于 2026-09-09 真机对比暗环与边框后接受的交付值；真机对比仍可校准数值，不修改处理的结构。
- 选中单元格的缩放必须保持为布局边界与点击目标不变的纯视觉变换；顺序角标必须保持为不占布局空间、不暴露第二焦点目标且不可交互的覆盖层。
- 多选复用普通每行数量网格不得改变普通 Content 的布局或启动行为。

## 验收条件

- 坞行在两种面板状态下都位于安全内容顶部，切换热区不变；切换从不滚动主列表；坞高与控件热区符合表现规范。

- 滑杆拖动连续预览且不持久化，指针抬起时恰好提交一次显示设置保存；抬起前被打断时，背景与读数立即回退到持久化状态且不保存；"仅一个未决保存"规则成立。
- 既有配置与缺失字段按契约默认规则迁移且不映射旧模式选择；背景不透明度百分比持久化、跨进程重建与重启存活，并出现在备份内容中。
- Home 与 Drawer 样式设置面板按已接受数值渲染契约边缘边框。
- 收藏多选在不改变布局的前提下复用普通网格；可用的未选中行不显示指示；选中单元格呈现缩放描边处理与左上角顺序角标；取消选择闭合编号空缺；被停用的已收藏行无角标、描边与缩放；普通选择切换、确认、保存与无障碍语义不变。
