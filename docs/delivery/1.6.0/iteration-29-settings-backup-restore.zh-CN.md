# 迭代 29：Settings 备份与恢复

> 适用版本契约：[1.6.0 交付](delivery.zh-CN.md)。本契约只定义已授权的交付边界。它不拥有执行状态、证据、提交或结果，其本身也不授权生产实现、commit、push、tag 或任何发布动作。

## 目标

按已被接受的产品契约完整交付 Settings 数据区的备份与恢复旅程：作者可以把完整的 Home 收藏状态与 Drawer 显示设置备份为一个由用户管理的本地 JSON 文件（经系统文档选择器），并在显式确认后以一次原子操作用所选备份文件替换当前状态，同时具备契约规定的反馈、取消、进行中、schema 兼容与有效性行为。

## 可观察结果

在主设备上，从 Settings：点击备份收藏与设置，会在用户选择的位置以带版本号与时间戳的建议文件名产出一个 JSON 文件；点击从备份恢复并确认后，以一次原子操作用备份内容替换当前收藏与显示设置；Home 与 Drawer 随后呈现恢复后的状态。成功、失败、取消与进行中行为符合数据节契约，包括方向性 schema 兼容规则，以及空备份与部分结构备份的既定有效性。

## 纳入工作

- Settings 数据区的两个入口：顺序、标题、带右侧箭头的主要设置项呈现，以及进入系统文档选择器。
- 备份序列化：把完整当前 Home 收藏状态（有序模块的类型、顺序、稳定身份、样式和模块内应用顺序）与完整 Drawer 显示设置写入一个带 schema 版本的 JSON 文件，建议文件名为 `avenor-backup-<版本名称>-<yyyyMMddHHmm>`。
- 恢复选择、详细确认弹窗（包含不可撤销警示的替换说明、`恢复` 与 `取消` 操作，取消/关闭/Back 均无操作），以及对收藏与显示设置的原子替换。
- 备份成功、备份失败、恢复成功、恢复失败四条本地化短提示，英文与简体中文。
- 方向性 schema 版本兼容（高于当前失败；等于或低于当前被接受并按当前 schema 解释），以及缺少收藏节、缺少显示设置节、已存在节内字段缺失、空备份的既定有效性。
- 备份写入或恢复应用进行期间两个数据入口不可交互，中断时不产生部分状态。
- 聚焦测试源：序列化往返、schema 兼容、部分文件有效性、弹窗与取消路径、不触碰当前状态的失败路径。

## 排除工作

- 任何形式的自动、定时、云或上传备份；备份文件加密。
- Home 收藏状态与 Drawer 显示设置之外任何状态的备份或恢复。
- `1.6.0` 版本标识更新（`versionName`/`versionCode`）——仍属版本级收尾事项，除非后续授权修订将其分配到本迭代。
- 样式编辑弹窗阴影与磨砂玻璃呈现调整；UI 动画与体验打磨工作。
- 第三方 License 展示。

## 技术改动区域

- Settings UI：两个数据入口、确认弹窗、提示呈现，以及进行中操作的入口禁用状态。
- 备份与恢复序列化：schema 版本、收藏与显示设置的 JSON 结构、建议文件名构造、方向性兼容解释。
- 状态存储：与既有版本化原子持久化一致的收藏与显示设置原子替换路径；备份排除与应用私有存储边界保持不变。
- 资源：两个入口标题、弹窗正文与操作、四条短提示的英文与简体中文字符串。
- Manifest 与权限：无；不新增权限，预计无 manifest 变更。
- 测试：覆盖上述行为的聚焦本地与 instrumentation 测试源。

## 依赖与顺序

本迭代依赖已被接受的产品契约与当前已集成主线；无其他已规划的版本内依赖。不得与另一条会改动收藏或显示设置存储、Settings UI 或共享字符串资源的工作线并发执行。

## 迁移与兼容影响

- 恢复按契约替换当前状态；除方向性 schema 规则外不引入数据迁移。
- 备份文件按用户选择位于应用私有存储之外，并按既有隐私边界排除于任何自动平台备份之外；本迭代不得改变该边界。
- Avenor 自有数据的 Android 云备份与设备传输行为仍由 Privacy 契约约束，保持不变。

## 安全、隐私、权限与许可影响

- 不引入新权限、网络、账号或外部服务。
- 备份文件不加密、由用户在 Avenor 私有存储之外管理，Privacy 契约已有披露；本迭代必须保证文件内容不超出契约的收藏与显示设置状态。
- Privacy 文案无需变更；若实现发现与 Privacy 声明存在重大偏差，停止并取得作者方向。

## 风险与未决决策

- OEM 文档选择器可能忽略或改变建议文件名；契约把最终命名交给系统选择器，因此各 OEM 差异属于可接受的呈现差异，其本身不构成缺陷。
- 跨语言区域与 12/24 小时制的时间戳构造必须始终产出 `yyyyMMddHHmm` 形式；出错会静默改变建议文件名。
- 恢复与其他进行中设置持久化之间的竞争不得产生混合状态；原子替换路径必须同时覆盖两个存储。
- 部分文件规则（缺少显示设置节时恢复为 Avenor 默认值）已由作者于 2026-09-07 在接受部分结构备份有效时确认；若真机使用显示该默认重置解读令人意外，重开它属于产品决策而非实现选择。

## 验收条件

- 两个数据入口按契约顺序出现，采用主要设置项呈现与右侧箭头，并在不新增权限的情况下打开系统文档选择器。
- 备份在建议文件名下写入一个含完整收藏与显示设置状态的带 schema 版本 JSON 文件；取消不写入任何内容且不显示提示；成功与失败显示契约的本地化提示。
- 恢复显示详细确认弹窗；取消、关闭与 Back 均不产生变化；确认后原子替换两个存储并显示契约成功提示；Home 与 Drawer 在下一次展示时呈现恢复后的状态。
- 不可读、格式错误与更高 schema 的文件在不覆盖当前状态的前提下失败并显示契约失败提示；等于或低于当前 schema 的备份、缺节备份、缺字段情形与空备份均按有效性规则表现。
- 备份写入或恢复应用进行期间，两个数据入口不可交互，中断不遗留部分状态。
- 所有新增用户可见字符串均有英文与简体中文资源，名称完全对齐。
- 普通 Settings 导航、状态刷新，以及恢复数据之外已被接受的 Home 与 Drawer 行为无回归。

## 验证要求

除被显式提升为强制外，以下为推荐场景：

- 主物理设备往返：备份、修改状态、恢复，并在 Home 与 Drawer 中核对恢复后的收藏与显示设置。
- 两个选择器与确认弹窗的取消路径；弹窗上的 Back 行为。
- 失败路径：不可读文件、格式错误 JSON、截断文件，以及 schema 版本高于当前的文件。
- 兼容路径：当前 schema 版本的备份、手工构造的更低 schema 备份、缺少显示设置节的备份、缺少收藏节的备份，以及空备份。
- 进行中行为：写入/应用期间的重复入口点击；备份与恢复应用期间的进程中断。
- 英文与简体中文资源的字符串对齐。
- 恢复后普通 Settings 导航与状态刷新的回归。
