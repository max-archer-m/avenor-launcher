## 版本意图

`1.6.0` 交付作者于 2026-09-07 确认为下一版本首个改动的 Settings 本地备份与恢复契约；该契约此前在 `1.5.0` 范围边界中被顺延。选定的结果让作者可以把完整的 Home 收藏状态与 Drawer 显示设置导出为一个由用户管理的本地 JSON 文件，并在之后通过显式确认用备份内容替换当前状态。本版本同时交付作者同日拍板的 Drawer 拖动收藏旅程：长按并拖动合格的 Drawer 应用，经 Home 编辑模式目的地以一次原子操作加入收藏。作者于 2026-09-08 指定并于 2026-09-08 与 2026-09-09 修订的第三个迭代交付已接受的呈现与行为重构：Home 编辑坞移至安全内容顶部并配合面板槽位交换动画、Drawer 背景重构为带百分比读数的连续背景不透明度滑杆、共享样式设置面板边缘边框，以及重构为统一覆盖角标的收藏多选呈现。按作者对本版本的方向，本版本内容仍为功能叠加与优化；契约行为之外的 UI 动画与体验打磨不在本版本范围内。

## 纳入范围与用户旅程

在 Settings 中，作者可以点击备份收藏与设置，把包含完整当前 Home 收藏状态与 Drawer 显示设置的一个 JSON 文件，通过系统文档选择器写入所选位置，并使用带版本号与时间戳的建议文件名；可以点击从备份恢复，选择备份文件并在详细确认弹窗之后，以一次原子操作替换完整当前状态。成功与失败均使用本地化短提示；选择器取消与进行中行为均有定义；schema 兼容具有方向性；部分结构化的备份具有明确有效性。

在普通 Drawer 与搜索结果中，作者可以长按合格应用并拖动，经程序化 Drawer-to-Home 过渡进入 Home 编辑模式，在编辑模式目的地松手即以一次原子操作加入收藏；不合格行显示契约 Toast，取消路径停留在普通 Home、不返回 Drawer。

在 Home 编辑模式中，作者使用安全内容顶部的固定编辑坞，并看到样式设置面板以不遮挡列表的槽位交换动画展开与收起。在 Drawer 显示设置中，作者在连续百分比滑杆上以实时预览选择背景不透明度，读数显示当前百分比；两个界面上的样式设置面板渲染已接受的边缘边框。在收藏多选中，选中行在缩放、描边的单元格上呈现覆盖顺序角标，选择模型不变。已被接受的 Home 模块模型、Drawer 行为与隐私边界保持不变。

## 排除项

- 自动备份、定时备份、云同步、云备份、设备间传输，以及对备份文件的任何上传。
- Home 收藏状态与 Drawer 显示设置之外的任何状态的备份或恢复；备份文件不加密。
- 纵向收藏列表——作者于 2026-09-07 确认不进入本版本。
- 第三种收藏模块类型（列收藏）——作者于 2026-09-07 确认在出现明确布局需求前不进入本版本。
- 契约行为与契约编辑坞面板动画之外的体验打磨工作——按作者方向排除。
- 第三方 License 展示——直至其独立的盘点与验收条件满足。
- 正式发布产物、公开分发、tag、里程碑或 GitHub Release。

## 技术方案与风险

实现细节由开发负责。交付必须保持版本化原子收藏文件持久化及其备份排除、当前权限边界（不新增权限）、仅本地处理，以及已被接受的 Home 与 Drawer 状态。备份文件的 schema 版本遵循 Settings 契约中的方向性兼容规则：高于当前 schema 的版本失败，等于或低于当前 schema 的版本按当前 schema 解释。

主要风险：OEM 文档选择器行为差异、建议文件名与时间戳在跨语言区域下的呈现、部分文件与字段缺失的解释、恢复与其他进行中设置持久化之间的竞争、恢复应用已不存在的身份，以及普通 Settings 导航与状态刷新的回归。
