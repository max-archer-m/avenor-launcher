## 版本意图

`1.6.0` 交付作者于 2026-09-07 确认为下一版本首个改动的 Settings 本地备份与恢复契约；该契约此前在 `1.5.0` 范围边界中被顺延。选定的结果让作者可以把完整的 Home 收藏状态与 Drawer 显示设置导出为一个由用户管理的本地 JSON 文件，并在之后通过显式确认用备份内容替换当前状态。本版本同时交付作者同日拍板的 Drawer 拖动收藏旅程：长按并拖动合格的 Drawer 应用，经 Home 编辑模式目的地以一次原子操作加入收藏。按作者对本版本的方向，本版本内容仍为功能叠加与优化；UI 动画与体验打磨不在本版本范围内。

作者已确认但尚未分配到迭代的下一版本方向——样式编辑弹窗周围阴影更明显，以及磨砂玻璃暗度/模糊校准（是否改为可调强度仍待定）——作为本版本或后续版本后续迭代的候选范围保留。在被某个迭代契约选中之前，它们不属于已纳入范围。

## 纳入范围与用户旅程

在 Settings 中，作者可以点击备份收藏与设置，把包含完整当前 Home 收藏状态与 Drawer 显示设置的一个 JSON 文件，通过系统文档选择器写入所选位置，并使用带版本号与时间戳的建议文件名；可以点击从备份恢复，选择备份文件并在详细确认弹窗之后，以一次原子操作替换完整当前状态。成功与失败均使用本地化短提示；选择器取消与进行中行为均有定义；schema 兼容具有方向性；部分结构化的备份具有明确有效性。

在普通 Drawer 与搜索结果中，作者可以长按合格应用并拖动，经程序化 Drawer-to-Home 过渡进入 Home 编辑模式，在编辑模式目的地松手即以一次原子操作加入收藏；不合格行显示契约 Toast，取消路径停留在普通 Home、不返回 Drawer。已被接受的 Home 模块模型、Drawer 行为与隐私边界保持不变。

## 排除项

- 自动备份、定时备份、云同步、云备份、设备间传输，以及对备份文件的任何上传。
- Home 收藏状态与 Drawer 显示设置之外的任何状态的备份或恢复；备份文件不加密。
- 纵向收藏列表——作者于 2026-09-07 确认不进入本版本。
- 第三种收藏模块类型（列收藏）——作者于 2026-09-07 确认在出现明确布局需求前不进入本版本。
- 样式编辑弹窗阴影与磨砂玻璃呈现调整——未分配的候选方向，非已选定范围。
- 本版本内的 UI 动画与体验打磨工作——按作者方向排除。
- 第三方 License 展示——直至其独立的盘点与验收条件满足。
- 正式发布产物、公开分发、tag、里程碑或 GitHub Release。

## 技术方案与风险

实现细节由开发负责。交付必须保持版本化原子收藏文件持久化及其备份排除、当前权限边界（不新增权限）、仅本地处理，以及已被接受的 Home 与 Drawer 状态。备份文件的 schema 版本遵循 Settings 契约中的方向性兼容规则：高于当前 schema 的版本失败，等于或低于当前 schema 的版本按当前 schema 解释。

主要风险：OEM 文档选择器行为差异、建议文件名与时间戳在跨语言区域下的呈现、部分文件与字段缺失的解释、恢复与其他进行中设置持久化之间的竞争、恢复应用已不存在的身份，以及普通 Settings 导航与状态刷新的回归。

强制版本环境为一台作者指定的主物理设备。完成要求：设备上完整的备份 → 恢复往返、确认与取消路径验收、不可读/格式错误/更高 schema 文件的失败路径行为、恢复数据之外已被接受的 Home 与 Drawer 状态保持不变，且无已知的纳入路径崩溃、ANR、破坏性配置错误、错误身份启动或导航死胡同。
