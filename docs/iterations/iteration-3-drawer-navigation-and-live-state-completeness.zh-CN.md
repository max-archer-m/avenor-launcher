# 迭代 3：Drawer 导航与实时状态完整性

> 英文语义源：[iteration-3-drawer-navigation-and-live-state-completeness.md](iteration-3-drawer-navigation-and-live-state-completeness.md)。
>
> 本迭代适用于 [Avenor Launcher 1.0.0 交付契约](../versions/1.0.0/delivery-contract.zh-CN.md)，定义一个产品增量及其必需证据。本文不授权实现、不批准候选架构，也不声明迭代完成。项目作者必须明确授权实现。

## 目标

完成 `1.0.0` Drawer 产品行为，使应用发现面对 locale 感知导航、实时清单变化和真实触控下的 Home/Drawer 手势仲裁时仍然快速、稳定且安全。

- [产品设计基础约束](../product/design-foundations.zh-CN.md)

## 可观察结果

作者能够通过稳定的 locale 感知分组、列表滚动或字母索引找到预期可启动条目；在 Home 与 Drawer 之间连续导航；并在应用发生变化时观察到正确 Drawer 状态，不发生意外激活或不稳定排序。

## 纳入工作

- 完成 Drawer 契约定义的 locale 感知分组、稳定排序、章节锚点和同序决胜规则。
- 完成 `#` 与非空 A-Z 字母索引、活动字符气泡、直接选择、连续滑动、分步触觉反馈，以及需要时的独立索引滚动。
- 在实时清单更新期间保留或确定性调整当前锚点和相对位置。
- 处理应用添加、移除、启用、禁用、重命名、图标、badge 和暴露的分身/资料变化。
- 完成可逆 Home/Drawer 过渡、进度、不透明度、释放阈值、指向目标的 fling、回弹、取消和 Back 行为。
- 完成列表边界手势转移、pointer 取消、额外 pointer 安全和字母索引独占所有权。
- 防止过渡和索引手势意外启动、长按或滚动应用条目。
- 在产品契约要求时，在同一进程中保留有意义的 Drawer 位置。

## 排除工作

- 应用操作面板和应用信息操作。
- 收藏创建、持久化、Home 收藏启动、移除、调和或恢复。
- Settings 齿轮行为，因为 Settings 排除在 `1.0.0` 外；不添加占位符。
- 产品范围排除的 TalkBack 专用替代字母索引交互和更广设备适配。
- 完整版本实测质量、release 签名、正式 APK、归档、tag 或分发操作。

## 技术影响面

- Locale 排序、章节分配、同序决胜、稳定身份和列表位置映射。
- 所选范围内的字母索引输入所有权、滚动、触觉反馈和无障碍语义。
- 项目所有的过渡控制器，以及 Home 滚动、Drawer 滚动、界面过渡与索引输入之间的仲裁。
- 清单回调串行化、状态更新、陈旧条目防止和位置保留。

产品契约定义可观察的手势与排序行为。准确动画原语、状态类型和实现算法仍是代码层选择，除非它们形成重大架构决定。

## 依赖和序列

- 迭代 2 已关闭，并具有已验收清单、身份、列表、Retry 和准确条目启动行为。
- 所选过渡状态模型可以扩展，而无需替换已验收 Home 或清单边界。
- 项目作者明确授权本迭代。
- 只有能够添加长按且不与过渡、列表或索引 pointer 所有权冲突，完成本迭代才会解锁迭代 4。

## 迁移和兼容性影响

- 不增加生产持久化 schema。
- 稳定排序与位置行为必须与迭代 2 选择的身份模型兼容。
- 手势行为需要真机触控证据；模拟器输入只作为功能性证据。
- 小屏和更广形态适配继续排除在 `1.0.0` 外。

## 安全、隐私、权限和许可证影响

- 不需要新增敏感权限、网络行为、数据收集或外部服务。
- 实时清单数据保持在现有本地最小权限边界内。
- 通过解析后的依赖图和 merged manifest 审查触觉反馈和 UI 依赖。
- 会扩大权限、数据或许可证义务的候选依赖，在集成前需要审查。

## 风险和未解决决定

- 手势仲裁是最高的自定义 UI 风险，可能在真实硬件上暴露产品/实现不匹配。
- Locale 行为可能因 API 级别和语言配置而异。
- OEM 清单回调可能突发到达，或呈现不完整的瞬态状态。
- 即使身份仍然不同，平台提供的分身/资料 badge 也可能缺失；Avenor 自有回退处理不在范围内。
- 任何阻止纳入行为的 OEM 限制都需要项目作者处置，不得静默接受。

## 验证计划

- 对排序、章节分配、同序决胜、锚点回退和状态归约进行单元测试。
- UI 测试覆盖索引选择/滑动、加载/错误恢复、Back、过渡阈值、fling 决策、取消和意外激活防止。
- 在自动化切实可行时，验证实时添加/移除/禁用/重命名以及无变化刷新行为。
- 在两台真机上验证真实触控过渡、列表边界转移、索引所有权、触觉反馈和位置连续性。
- 运行 API 31 的分组、导航、列表/索引布局和 Back 功能兼容性检查。
- 记录命令、locale、环境、构建身份、源码 commit、步骤、适用时的 trace 和结果。

## 验收证据

关闭前记录：

- 稳定分组、排序、索引、锚点和实时更新结果；
- 手势位移、阈值、fling、回弹、取消和 pointer 安全证据；
- Samsung 和 Pixel 的真机观察结果；
- API 31 兼容性结果；
- 自动化命令和保留的聚焦证据；
- 每个未解决 OEM 或产品不匹配及其作者处置。

不能仅因本契约存在就视为验收证据存在。

## 相关决定、commit 和 tag

- 手势或状态所有权 ADR：仅在已证明决定重大且持久时添加。
- 实现 commit：根据实际工作记录。
- Tag：本迭代未授权也不要求 tag。

## 最终结果

只有 Drawer 发现、导航、实时状态行为和 Home/Drawer 交互在必需的聚焦环境中满足所选产品契约，并具有可追踪证据后，本迭代才关闭。在此之前不声明完成。
