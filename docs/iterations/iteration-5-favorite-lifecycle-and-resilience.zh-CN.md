## 可观察结果

作者能够找到并启动暴露的应用，将其添加到 Home，从 Home 启动，重启进程或设备而不丢失收藏，从任一适用操作面板上下文移除，并确认移除只改变 Home 而 Drawer 仍然正确。瞬态清单或启动失败不会删除收藏。

## 纳入工作

- 从 Home 和 Drawer 打开应用操作面板，并为当前状态提供正确收藏操作。
- 从 Home 启动可用收藏，并抑制快速重复激活。
- 从 Home 或 Drawer 移除收藏，且不从 Drawer 移除其可启动条目。
- 按要求在操作和平台返回后保留 Drawer 位置与 Home 状态。
- 在进程重建和设备重启后持久化有效身份与顺序。
- 使用准确身份，对照成功清单快照调和收藏。
- 在加载、清单失败、瞬态启动失败、禁用状态、资料锁定状态或身份未确认期间保留收藏。
- 只有成功刷新确认该准确身份永久消失后，才自动移除收藏。
- 对禁用和暂时不可用收藏提供本地化反馈，且不进行破坏性状态变更。
- 为主条目和平台暴露的分身/资料条目完成所选离线收藏路径。
- 在无法可靠读取持久化状态时，确保收藏变更保持禁用，且不实现排除的恢复 UI。

## 排除工作

- 收藏排序模式、拖动把手、位置交换、排序触觉反馈和排序自动滚动。
- 完整收藏损坏修复、重置、导出、备份、恢复或面向用户的只读恢复 UI。
- 平台应用快捷操作、卸载、禁用、移除分身、Settings、手动语言选择或其他排除操作。
- 完整版本性能阈值、release 签名、正式 APK、归档、tag 或分发操作。

## 技术影响面

- Home/Drawer 共享收藏状态和操作面板操作选择。
- 启动节流、不可用状态刷新、确定性调和、确认消失，以及回调/变更串行化。
- 跨进程和设备重启的持久化、读取失败、变更门控和 schema 演进。
- 跨 Home、Drawer、操作面板、平台启动和本地存储的聚焦端到端状态与 UI 验证。

实现细节留在代码和测试中。新形成的重大状态所有权、调和或持久化决定记录在架构文档或 ADR 中，不在此重复。

- 不需要新增敏感权限或服务。
- 平台启动和应用信息操作处理失败时不暴露原始异常或删除数据。

## 风险和未解决决定

- OEM 回调可能难以通过单个事件证明永久消失。
- 锁定或暂时不可用的资料可能表现得像已移除。
- 并发 Retry、刷新、启动和收藏变更若未串行化，可能发布陈旧状态。
- 设备重启证据可能暴露分身/资料条目的身份不稳定。
- 必需设备上无法满足的纳入行为需要契约不匹配决定，不得静默删除或回退到仅软件包名。
