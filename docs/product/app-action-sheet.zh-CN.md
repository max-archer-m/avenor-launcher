# 应用操作面板

> 英文语义源：[app-action-sheet.md](app-action-sheet.md)。

## 呈现

应用操作面板是从 Home 或 Drawer 长按应用后打开的模态 Bottom Sheet。

- 使用深色表面与浅色文字，并保持系统状态栏图标为浅色。
- 顶部显示一条浅色短横线作为拖动柄。
- 底层界面覆盖灰色遮罩。
- 点击遮罩、将面板拖动到底部或按 Back 均可关闭。
- 关闭前，底层应用界面不能接收点击、长按或滚动。
- 点击操作后先调用对应操作，再关闭面板；当前产品定义不增加独立的成功反馈。

## 内容顺序

从上到下依次为：

1. 左侧应用名称和右侧应用信息图标。
2. 左右各缩进 12dp 的浅色分割线。
3. 平台提供的应用快捷操作，每项为图标加名称。
4. 左右各缩进 12dp 的浅色分割线。
5. 横向排列的启动器操作，每项图标在上、名称在下。

平台没有提供应用快捷操作时，隐藏整个应用快捷操作区。当前契约不定义应用快捷操作异常过多时的溢出行为。

## 应用身份与信息

- 应用名称不可点击。
- 顶部不展示应用图标。
- 平台 badge 计划展示在面板右下角，但其脱离应用图标后的独立视觉含义仍待确认。
- 点击信息图标后进入系统应用信息界面。
- 从系统应用信息返回时不恢复面板，并刷新对应应用状态。
- 系统界面无法打开时，向用户展示简短且已本地化的错误提示。

## 启动器操作

- 启动器操作使用五个固定横向槽位。少于五项时占据其指定槽位，不在整个宽度中重新均分。
- 启动器操作最多五项；该限制不适用于平台应用快捷操作。
- Home 中展示：取消收藏、排序，以及可用时的卸载。
- Drawer 中根据当前收藏状态展示收藏或取消收藏，并在可用时展示卸载。
- 收藏后将应用追加到 Home，Drawer 保留当前位置。
- 取消收藏后关闭面板，并从 Home 移除对应条目。
- 系统不允许卸载或只允许停用时，不展示卸载。
- 对应用分身执行卸载表示删除该分身，不得卸载主应用。
- 破坏性确认和实际删除行为由系统控制。

## 图标

- 收藏：爱心。
- 取消收藏：裂开的爱心。
- 排序：纵向箭头。
- 卸载：垃圾桶。
- 应用信息：信息符号。

最终图标资产及无障碍描述由视觉和实现规格补充。
