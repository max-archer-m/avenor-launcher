# 应用操作面板

> 英文语义源：[app-action-sheet.md](app-action-sheet.md)。空间草图见共享的[应用操作面板线框](../wireframes/app-action-sheet.txt)，阅读规则见[线框索引](../low-fidelity-wireframes.zh-CN.md)。

## 呈现

应用操作面板是从 Home 或 Drawer 长按应用后打开的模态 Bottom Sheet。

- 使用深色表面与浅色文字，并保持系统状态栏图标为浅色。
- 顶部显示一条浅色短横线作为拖动柄。
- 底层界面覆盖灰色遮罩。
- 点击遮罩、将面板拖动到底部或按 Back 均可关闭。
- 关闭前，底层应用界面不能接收点击、长按或滚动。
- 点击操作后先调用对应操作，再关闭面板；当前产品定义不增加独立的成功反馈。

## 内容顺序

从上到下依次为：

1. 左侧应用名称和右侧标准 `24dp` 应用信息图标。
2. 左右各缩进 `16dp` 的浅色分割线。
3. 可选的应用快捷操作区：包含平台提供的快捷操作，每项为标准 `24dp` 图标加名称，并在区域末尾包含一条左右各缩进 `16dp` 的浅色分割线。
4. 横向排列的启动器操作，每项使用标准 `24dp` 图标，图标在上、名称在下。

平台没有提供应用快捷操作时，隐藏完整的应用快捷操作区，包括该区域末尾的分割线。应用身份信息下方的第一条分割线仍然保留，使身份信息与启动器操作之间只有一条边界，不出现连续重复分割线。

当前契约不为异常多的平台快捷操作定义专门的溢出交互；只有真实应用证明存在需要后，才作为可叠加能力补充。无论数量如何，实现不得崩溃，也不得绘制到受保护的系统界面区域。

## 应用身份与信息

- 应用名称不可点击。
- 顶部不展示应用图标。
- 对应用分身，在 Bottom Sheet 右下角独立展示平台提供的分身 badge，以遵循作者三星设备上观察到的身份提示方式。
- Badge 使用 `12dp × 12dp` 视觉区域，对齐 Bottom Sheet 右下角，不设置向外偏移。
- Badge 仅用于装饰，不接收输入、不占用启动器操作槽位，也不为其预留内容布局空间；主应用不展示。
- 点击信息图标后进入系统应用信息界面。
- 从系统应用信息返回时不恢复面板，并刷新对应应用状态。
- 系统应用信息界面无法打开时，展示短 Toast `无法打开应用信息`，关闭面板，保留底层 Home 或 Drawer 位置，并且不改变收藏状态。

## 启动器操作

- 启动器操作使用从左到右排列的五个固定横向槽位。可见操作从最左侧槽位开始紧缩排列；隐藏操作不留下中间空位，未使用槽位保留在右侧。操作不在整个宽度中重新均分。
- 每个启动器操作的完整“图标 + 标签”条目是一个交互目标；`24dp` 图标不是独立或更小的触控目标。
- 启动器操作最多五项；该限制不适用于平台应用快捷操作。
- Home 操作顺序为取消收藏、编辑、卸载。编辑操作打开 Home 编辑模式，并在只有一个收藏时仍然可用；卸载不可用时隐藏，后续可见操作向左移动。
- Drawer 操作顺序为根据当前状态显示收藏或取消收藏，然后是可用时的卸载。卸载占据下一个左侧槽位，不可用时隐藏。
- 收藏持久化状态无法可靠读取时，Avenor 无法判断所选应用当前是否已收藏。将添加收藏或取消收藏操作替换为一个禁用的收藏槽位，标签为 `收藏暂不可用`，使用标准爱心图标。该槽位不能接收输入，也不展示 Toast；应用信息和其他非收藏操作继续遵循各自的可用性规则。收藏数据后续读取成功时，根据恢复的状态重新显示适用的添加收藏或取消收藏操作。
- 新增收藏将应用追加到主收藏，随后关闭面板，并保留 Drawer 当前锚点和相对滚动位置；不跳转到 Home，也不进入编辑模式。主收藏可见视口已经铺满时仍接受新增，内容溢出后主收藏变为可滚动；不自动把条目放入伴收藏。
- 取消收藏后关闭面板，并从 Home 移除对应条目。从 Drawer 取消收藏时，应用仍保留在 Drawer，当前锚点和相对滚动位置不变。
- 系统不允许卸载或只允许停用时，不展示卸载。
- 对应用分身，只有平台能够确认操作仅删除当前选中分身、不会卸载主应用时，才展示卸载。无法保证时隐藏卸载，并保留通过应用信息进入系统管理的渠道。绝不把“删除分身”降级成“卸载主应用”。
- 破坏性确认和实际删除行为由系统控制。
- 用户取消系统卸载确认后，返回原 Home 或 Drawer 位置，不恢复面板，并刷新应用状态。
- 系统卸载界面无法打开时，展示短 Toast `无法打开卸载界面`，关闭面板，保留底层 Home 或 Drawer 位置，并且不改变收藏状态。
- 当前产品范围不为平台应用快捷操作调用失败增加独立处理。

## 图标

- 收藏：爱心。
- 取消收藏：裂开的爱心。
- 编辑：纵向箭头。
- 卸载：垃圾桶。
- 应用信息：信息符号。

最终图标资产及无障碍描述由视觉和实现规格补充。
