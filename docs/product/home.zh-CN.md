# Home 交互规格

> 英文语义源：[home.md](home.md)。公共导航见 [navigation.zh-CN.md](navigation.zh-CN.md)，公共视觉规则见 [design-foundations.zh-CN.md](design-foundations.zh-CN.md)。

## 目的与结构

Home 是 Launcher 主界面，内容按从上至下的单列结构排列：

1. 基础信息区：时间在上，日期与星期在下。
2. 收藏应用列表区：按用户定义顺序展示所有已保存的可启动应用条目。

基础信息区在普通情况下约占可用纵向空间的 20%–30%，但内容完整和无障碍优先于强制百分比。收藏列表占用剩余空间，从区域顶部开始排列，仅在内容超出时滚动；滚动条只在滚动期间展示。

Home 内容采用 16dp 横向内边距和暂定 32dp 纵向内边距。这里使用 padding 而不是 margin，因为这些数值表达的是 Home 容器边界与内部内容之间的安全距离。

## 时间、日期与星期

- 时间左对齐并位于日期上方，采用 `57sp` 字号、`64sp` 行高和粗体。所选系统字体支持时使用等宽数字特性，避免分钟变化导致时钟宽度跳动。
- 时间跟随系统 12/24 小时制，不显示秒。
- 日期与星期在时间下方左对齐，采用 `16sp` 字号、`24sp` 行高和正常字重，格式跟随当前语言区域，例如简体中文为 `2月1日 星期二`。
- 点击可见时间文字，通过隐式调用进入系统时钟，不指定具体包名。
- 点击可见日期星期文字，通过隐式调用进入系统日历，不指定具体包名。
- 时间所在行高度至少为 `64dp`，不在其实际行区域之外另行扩大触控范围。
- 日期星期行的可见高度为 `40dp`，文字垂直居中；触控输入层可以将可聚焦目标自动扩展到至少 `48dp`，但不得绘制更大的背景或改变可见的 40dp 布局。

## 收藏列表

- 新安装时收藏为空，显示简洁的空状态，引导用户前往 Drawer 添加应用。
- 从 Drawer 收藏应用后，将其追加到列表末尾。
- 同一个可启动应用条目不能重复收藏。主应用与应用分身是不同条目，可以分别收藏。
- 条目使用竖直单列，包含平台提供的应用图标、存在时的平台分身或资料 badge，以及应用名称。
- 应用名称只占一行。能够完整展示时保持静止；发生溢出时，使用 [design-foundations.zh-CN.md](design-foundations.zh-CN.md) 定义的公共跑马灯行为。
- 图标形状和 badge 完全采用平台提供的呈现，并在 Home、Drawer 及相关应用界面中保持一致。
- 点击条目后立即启动应用，普通点击不产生震动，并抑制短时间内的重复启动。
- 长按条目时产生长按触觉反馈，并打开 [app-action-sheet.zh-CN.md](app-action-sheet.zh-CN.md) 定义的应用操作面板。
- 应用清单确认某个条目已永久消失后，将其从收藏中移除。暂时不可用和恢复规则仍待定义。

## 排序模式

- 排序模式只用于 Home 收藏列表，从被选中收藏条目的启动器操作进入。
- 每个收藏条目右侧显示三条横线形式的拖动柄，视觉上可参考常见媒体列表的排序手柄。
- 将条目拖过另一个已保存位置时交换位置，并针对已完成的位置变化提供一次短震动。
- 变化后的顺序立即保存。
- 系统 Back 是当前唯一退出排序模式的渠道，退出时不撤销已经完成的移动。

## 验收意图

- 空、较短和可滚动收藏列表均保持相同的顶部对齐结构。
- 主应用与应用分身通过平台 badge 保持可辨识。
- 同一进程内返回 Home 时保留有意义的列表状态；进程重建遵循 [navigation.zh-CN.md](navigation.zh-CN.md)。
