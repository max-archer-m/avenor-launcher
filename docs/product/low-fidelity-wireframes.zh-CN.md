# Avenor Launcher 低保真线框图

> 英文语义源：[low-fidelity-wireframes.md](low-fidelity-wireframes.md)。

线框图用于可视化当前产品契约中的空间层级、区域关系和主要内容顺序，不定义像素级最终视觉，也不规定实现结构。规范性行为仍由对应交互规格定义。

每份语言中立的 ASCII 画布只在 `docs/product/wireframes/` 下存储一次。全屏界面通常以约 80 列 x 96 行为目标，模态界面可以更短。Home 使用完整画布表达不可滚动屏幕中的内容驱动模块，以及不属于产品区域的未分配透明空间。画布中的英文标签是结构标注，不是用户可见文案。

## 阅读规则

- `L1` 和 `L2` 表示两个地位相同纵向收藏列表中的示意条目。画布展示默认“中”尺寸：`40dp` 图标、`56dp` 条目高度和 `16sp/24sp` 名称。“大”使用 `48dp`、`64dp` 和 `18sp/28sp`；“小”使用 `32dp`、`48dp` 和 `14sp/20sp`。
- 收藏构图每侧使用 `8dp` 内部 padding，列表间距为 `16dp`。一个列表使用全宽；两个可见列表平均分配剩余宽度。条目使用 `16dp` 图标名称间距和当前拖动柄几何；普通模式与编辑模式保持每个列表选定的尺寸。
- 编号条目只说明位置，不建立固定容量。每个列表仅在内容溢出时独立滚动；失去最后一个条目时删除该列表。收藏栏失去最后一个应用条目时同样删除。
- Drawer 操作面板新增默认加入物理位置最左侧的纵向列表，调整列表顺序会改变该目标。Home 编辑模式中，独立不透明预览跟随触控点，源槽位保持稳定。纵向列表和收藏栏都是应用容器；预览在跨容器有效松手前保持源尺寸，之后采用目标列表尺寸或固定收藏栏呈现。
- 在同容器中拖到另一应用主体会立即交换并持久化；同容器间隙不插入。在另一容器中，已有主体表示交换，有效的首部、条目间、末尾或空临时边界表示插入。跨容器反馈互斥，并只在有效松手后保存一次操作。
- 目标反馈及横向或纵向边缘自动滚动都使用手指触控点。应用拖动在有效的目标视口 `48dp` 边缘区内停留约 `120ms` 后开始渐进自动滚动；仅当前有效容器滚动，其活动边缘显示最高 `8%` 不透明度、位于插入与交换反馈下方且不可交互的浅色前景渐变。无效松手保留最后一次成功持久化的同容器交换，并丢弃尚未保存的跨容器目标。
- 应用名称保持一行，必要时使用末尾省略。
- 点状填充只表示空间已经分配，不规定可见纹理、颜色或额外图层。
- 次级收藏区位于收藏列表区下方，与其保持 `16dp` 纵向间距，使用完整的 Home 可用内容宽度，没有内容时高度为零。该区域最多包含五条高 `56dp` 的横向收藏栏；Home 本身不因该区域而纵向滚动。未分配的透明 Home 空间不是该模块。
- 每条收藏栏包含有限且由用户定义的 `128dp` 宽可启动条目序列，只有条目溢出时才横向滚动；收藏栏纵向间距为 `8dp`。条目使用固定且不可选择的“中”尺寸，展示 `40dp` 图标和一行 `16sp/24sp` 名称，以 `8dp` 间距左对齐，不重新均分未使用宽度。当前收藏栏不显示标题，也不预留标题高度。点击条目启动对应应用，长按条目打开现有应用操作面板。
- Home 编辑模式在每个收藏列表或收藏栏末尾增加水平居中的 `24dp` 加号及至少 `48dp` 的触控目标，并在列表少于两个时展示一条临时列表、收藏栏少于五条时展示一条临时收藏栏。同一 Drawer 画布同时表达普通和收藏多选模式：普通模式使用只有返回操作的透明顶部应用栏；多选模式将其替换为取消、适用的添加或新建目标说明和确认。每个应用图标左侧固定预留 `40dp` 区域并居中显示 `24dp` 空心圆；选中后以浅色角色填充、增加深色 `14sp/20sp` 序号，并为整行增加 `8%` 浅色背景。
- 进入多选时记录每个 Home 容器的滚动位置；取消时准确恢复。确认成功后保留所有非目标位置，仅在需要完整显示首个仍有效新增条目时最小滚动目标容器；临时容器从内容起点展示。
- 多选复用 Drawer 的 Loading 与 Error 内容状态，同时保留取消和目标说明。Loading 或完整 Error 隐藏条目、Settings 与 AlphabetIndex，并禁用确认；Error 在内存中保留有序选择，以供单次读取的重试或取消。可靠清单中所有条目均已收藏时，继续显示 disabled Content，不视为 Empty 或 Error。
- 编辑模式中的每个收藏都显示尾部 `24dp` 拖动柄及其宽 `48dp`、占满条目高度的热区，并在应用图标逻辑 start 上方边缘显示可见 `24dp` error 语义 X 角标及独立的至少 `48dp` 热区。热区可以覆盖不再交互的名称或图标呈现，但彼此不得重叠。移除立即持久化，并显示只对应最近一次操作的`已取消收藏`／`撤销` Snackbar。
- 已有内容的次级收藏模块使用共享编辑表面；每条收藏栏在浅色前景语义色 `12%` alpha 的 `1dp` 独立边界内保持透明，只在对应方向仍有更多横向内容时显示条件式边缘渐隐。
- 每条持久化可编辑收藏栏具有固定的 `48dp × 56dp` 两侧控制轨：逻辑 start 删除完整收藏栏，逻辑 end 纵向调整收藏栏顺序。只有一条持久化收藏栏时隐藏排序但保留控制轨；至少两条时显示，临时收藏栏不提供任一操作。中部应用视口在两者之间滚动，不调整 `128dp` 条目尺寸。删除完整收藏栏先显示默认确认 Dialog，再沿用只保留最近一次操作的`已删除收藏栏`／`撤销`。排序冻结完整可见收藏栏窗口；进入另一收藏栏主体时立即交换并持久化，间隙不插入。
- 每个持久化纵向列表在编辑模式视口内具有固定的 `48dp` 顶部控制栏；三个物理左右槽位依次为删除列表、当前尺寸和调整列表顺序。单列表隐藏排序，临时列表没有控制栏。控件在 `48dp` 热区内使用 `40dp` 圆形，只以不透明度反馈按压。尺寸菜单锚定按钮当前坐标、避让安全边界，并以完整 `64dp` 条目展示大／中／小；条目顺序为单选标记、按 `48dp/40dp/32dp` 展示的本地默认图标、再到文字。确认删除完整列表后显示`已删除列表`／`撤销`；可见视口静态预览进入另一列表主体时立即交换两个列表，列表间隙不插入。
- Home 基础信息区的标注只表示符合条件的空白区域；时间和日期触控目标不参与双击锁屏。

## 线框索引

- [Home](wireframes/home.txt) - 完整的 80 x 96 画布，表达内容驱动的纵向尺寸、当前双列表等宽状态及未分配的透明空间；普通 Home 只有一个列表时，该列表扩展至完整构图宽度。
- [Home 编辑模式](wireframes/home-edit-mode.txt) - 完整的 80 x 103 画布，表达编辑表面、持久化列表顶部控制栏与尺寸菜单、收藏拖动柄、列表末尾新增控件、临时列表和收藏栏入口，以及列表独立滚动。
- [Drawer](wireframes/drawer.txt) - 完整的 80 x 96 Content 状态画布，表达固定透明顶部应用栏、普通与多选应用栏语义、单列应用列表、与应用名称列对齐的非吸顶锚点、普通模式末尾设置分组和固定字母索引；全屏 Loading 与 Error 状态按 Drawer 契约隐藏该索引。
- [应用操作面板](wireframes/app-action-sheet.txt) - 80 x 80 模态状态画布，表达被阻断的背景、遮罩和 BottomSheet 内容顺序。
- [Settings](wireframes/settings.txt) - 完整的 80 x 96 画布，表达导航、默认 Launcher 状态和产品信息条目。

## 权威边界

线框图是可视化辅助，不是独立产品决定。线框图与规范性文字不一致时，以对应交互规格和产品基础需求为准。已经确认的空间契约发生变化时，应在同一次文档变更中同步更新线框图。
