# Avenor Launcher 低保真线框图

> 英文语义源：[low-fidelity-wireframes.md](low-fidelity-wireframes.md)。

线框图用于可视化当前产品契约中的空间层级、区域关系和主要内容顺序，不定义像素级最终视觉，也不规定实现结构。规范性行为仍由对应交互规格定义。

每份语言中立的 ASCII 画布只在 `docs/product/wireframes/` 下存储一次。全屏界面通常以约 80 列 x 96 行为目标，模态界面可以更短。Home 使用完整画布表达不可滚动屏幕中的内容驱动模块，以及不属于产品区域的未分配透明空间。画布中的英文标签是结构标注，不是用户可见文案。

## 阅读规则

- `P` 表示示意性的主收藏条目，使用 40dp 应用图标、默认 56dp 条目高度和 `16sp/24sp` 名称。
- `C` 表示示意性的伴收藏条目，使用 32dp 应用图标、默认 48dp 条目高度和 `14sp/20sp` 名称。
- 收藏构图每侧使用 `8dp` 内部 padding，55:45 两组之间使用 `16dp` 间距。每个条目四周均使用 `8dp` 内部 padding，并使用 `16dp` 图标名称间距。普通模式与编辑模式条目等高，拖动柄不会撑高行。
- 编号条目只说明位置，不建立固定容量。每个收藏分组仅在内容溢出时独立滚动。
- 从 Drawer 新增时默认加入主收藏。在 Home 编辑模式中，拖到另一组有效插入位置时移动收藏，拖到已有收藏的位置时交换两个收藏；模型不预设空槽。
- Home 编辑模式中，被拖动条目以约 `50%` 透明度的预览跟随触控点在 Home 安全内容区域内移动。只有两组收藏接受放置；插入线和交换边框是根据触控点展示的目标反馈，并在松手时提交。
- 应用名称保持一行，必要时使用末尾省略。
- 点状填充只表示空间已经分配，不规定可见纹理、颜色或额外图层。
- 底部次级收藏模块在适用的用户创建内容获得定义前不存在且高度为零；未分配的透明 Home 空间不是该模块。
- Home 基础信息区的标注只表示符合条件的空白区域；时间和日期触控目标不参与双击锁屏。

## 线框索引

- [Home](wireframes/home.txt) - 完整的 80 x 96 画布，表达内容驱动的纵向尺寸、55:45 收藏构图及未分配的透明空间。
- [Home 编辑模式](wireframes/home-edit-mode.txt) - 完整的 80 x 96 画布，只为可见模块表达编辑表面，并展示收藏拖动柄和分组独立滚动。
- [Drawer](wireframes/drawer.txt) - 完整的 80 x 96 Content 状态画布，表达单列应用列表、与应用名称列对齐的非吸顶锚点、末尾设置分组和固定字母索引；全屏 Loading 与 Error 状态按 Drawer 契约隐藏该索引。
- [应用操作面板](wireframes/app-action-sheet.txt) - 80 x 80 模态状态画布，表达被阻断的背景、遮罩和 BottomSheet 内容顺序。
- [Settings](wireframes/settings.txt) - 完整的 80 x 96 画布，表达导航、默认 Launcher 状态和产品信息条目。

## 权威边界

线框图是可视化辅助，不是独立产品决定。线框图与规范性文字不一致时，以对应交互规格和产品基础需求为准。已经确认的空间契约发生变化时，应在同一次文档变更中同步更新线框图。
