# Avenor Launcher 低保真线框图

> 英文语义源：[low-fidelity-wireframes.md](low-fidelity-wireframes.md)。

线框图用于可视化当前产品契约中的空间层级、区域关系和主要内容顺序，不定义像素级最终视觉，也不规定实现结构。规范性行为仍由对应交互规格定义。

每份语言中立的 ASCII 画布只在 `docs/product/wireframes/` 下存储一次。全屏界面通常以约 80 列 x 96 行为目标，模态界面可以更短。Home 的纵向比例属于当前契约，因此必须使用完整画布。画布中的英文标签是结构标注，不是用户可见文案。

## 阅读规则

- `P` 表示示意性的主收藏槽位，使用 48dp 应用图标和至少 64dp 交互目标。
- `C` 表示示意性的伴收藏槽位，使用 32dp 应用图标和至少 48dp 交互目标。
- 编号条目只说明位置，不建立固定容量。每个收藏分组仅在内容溢出时独立滚动。
- 从 Drawer 新增时默认加入主收藏。在 Home 编辑模式中，拖到另一组空位置时移动收藏，拖到已有收藏的位置时交换两个收藏。
- 应用名称保持一行，必要时使用末尾省略。
- 点状填充只表示空间已经分配，不规定可见纹理、颜色或额外图层。
- Home 底部区域只是预留空间；其中的填充不定义织带、轮播、分页或其他交互。

## 线框索引

- [Home](wireframes/home.txt) - 完整的 80 x 96 画布，表达约 20:60:20 的纵向构图和 60:40 的收藏构图。
- [Home 编辑模式](wireframes/home-edit-mode.txt) - 完整的 80 x 96 画布，表达三个编辑表面、收藏拖动柄和分组独立滚动。
- [Drawer](wireframes/drawer.txt) - 完整的 80 x 96 画布，表达单列应用列表、吸顶锚点和固定字母索引。
- [应用操作面板](wireframes/app-action-sheet.txt) - 80 x 80 模态状态画布，表达被阻断的背景、遮罩和 BottomSheet 内容顺序。
- [Settings](wireframes/settings.txt) - 完整的 80 x 96 画布，表达导航、默认 Launcher 状态和产品信息条目。

## 权威边界

线框图是可视化辅助，不是独立产品决定。线框图与规范性文字不一致时，以对应交互规格和产品基础需求为准。已经确认的空间契约发生变化时，应在同一次文档变更中同步更新线框图。
