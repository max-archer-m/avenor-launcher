# Home 表现规范

> 英文公共语义源：[home.md](home.md)。

## 职责

本文档是 Home 精确布局、字体、组件几何和视觉状态数值的权威来源。[Home 行为](../surfaces/home.zh-CN.md)负责状态与操作结果；[设计基础](../design-foundations.zh-CN.md)负责共享原则。

## 界面与基础信息

- Home 在 `safeDrawing` 内使用统一 `8dp` 内容 padding。相邻可见模块使用 `8dp` 间距。
- 基础信息模块不增加 padding。时间和日期行在已 padding 边界内使用 `8dp` 起止 margin，使行边界距对应安全边缘 `16dp`。时间行增加 `8dp` 顶部 margin，最终顶部距离为 `16dp`。日期文字再增加 `8dp` 起始 inset，距安全起始边缘 `24dp`，完整行目标仍位于 `16dp` 边界。
- 时间行至少高 `64dp`，使用 `57sp/64sp` 粗体 display 文字，并在支持时使用等宽数字。日期行高 `48dp`，使用 `16sp/24sp` 正常字重文字。
- Home 收藏列表区、纵向列表、收藏栏和收藏项不在 Home 内容 padding 之外增加外部 padding。正常和编辑模式保持这些外部边界。

## 纵向收藏列表

- 一个列表使用完整的已 padding 收藏区宽度；两个列表在 `8dp` 列表间距后平分宽度，并共享同一视口高度。
- 大尺寸使用 `48dp` 图标、`64dp` 项目高度和 `18sp/28sp` 正常字重名称；中尺寸使用 `40dp`、`56dp` 和 `16sp/24sp`；小尺寸使用 `32dp`、`48dp` 和 `14sp/20sp`。
- 收藏项不增加 padding。图标使用 `8dp` 起始 margin 并垂直居中，随后是 `16dp` 图标名称间距。名称遵循系统缩放，使用静态单行和尾部省略。
- 应用拖动手柄使用 `24dp` 图形，居中在物理右侧贴边、宽 `40dp`、占满项目高度且没有末端 margin 的目标内。

## 编辑表现

- 每个可编辑 Home 模块使用共享的轻微半透明浅灰编辑表面和小圆角。准确共享表面颜色、透明度与圆角为 `To be decided`。在确认前，当前资源值属于实现校准值而不是持久产品契约值，并且必须继续资源化。
- 应用移除控件位于物理左上角，使用白色 X 和纯错误红色 `20dp x 20dp` 背景。可见和交互边界均为 `20dp x 20dp`；这是作者接受的紧凑目标例外。
- 持久纵向列表具有高 `40dp` 的控制栏，不包含 padding、填充、完整控制栏圆角表面、外边框或后续间距。`1dp`、`12%` 透明度的浅色前景底部分割线将其与内容分隔。
- 三个 `40dp x 40dp` 控制目标贴齐物理右侧，按物理从右到左为重排、尺寸、移除。重排居中 `24dp` 图形；移除居中 `24dp x 24dp` 错误红色背景与白色 X；尺寸仅包含本地化值。只有一个列表时隐藏重排但保留其位置。
- 尺寸菜单使用三个 `64dp` 行。每行不随 RTL 镜像，依次为选择指示器、内置通用应用图标预览和本地化标签。预览尺寸为 `48dp`、`40dp` 和 `32dp`。
- 锚定尺寸菜单通常显示在尺寸控件下方 `4dp` 并与其居中对齐。需要在安全内容内横向或纵向限制时，至少保留 `8dp` 安全边界距离。
- 添加操作是至少高 `48dp` 且足以容纳标签的本地化纯文字目标，没有装饰容器或独立加号图标。

## 收藏栏

- 次要区域使用完整的已 padding Home 宽度，与相邻内容使用 `8dp` 间距。已填充收藏栏高 `56dp`，垂直间距为 `8dp`，且没有容器 padding。
- 每项使用 `8dp` 起始 inset、`40dp` 图标、`8dp` 图标名称间距、一行最多测量至 `64dp` 的 `16sp/24sp` 正常字重名称，以及 `8dp` 末端 inset。总宽度按内容测量，最大 `128dp`；较长名称使用尾部省略。项目间距为 `8dp`。
- 每项背景使用 `6%` 透明度的浅色前景角色，`1dp` 边框使用 `12%`，圆角为 `12dp`。
- 可编辑收藏栏使用两个相等的固定 `40dp x 56dp` 外侧轨道。起始轨道居中 `24dp x 24dp` 错误红色移除图形，末端轨道居中 `24dp` 重排手柄。每个轨道在水平两侧各保留 `8dp`；`1dp` 分割线将轨道与视口分隔。
- 每个可编辑收藏栏内部透明，使用 `1dp`、`12%` 透明度的浅色前景轮廓和 `12dp` 圆角。

## 拖动与溢出反馈

- 应用自动滚动使用向内 `48dp` 的浅色前景渐变，从透明上升至最多 `8%`。它不改变几何、不拦截输入，并位于插入和交换反馈下方。
- 拖动图形在有效跨容器释放前保持来源表现，释放后应用目标表现。
