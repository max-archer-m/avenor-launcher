# Home 表现规范

> 英文公共语义源：[home.md](home.md)。

## 职责

本文档负责 Home 精确布局、字体、组件几何与视觉状态。[Home 行为](../surfaces/home.zh-CN.md)负责状态和操作结果；[设计基础](../design-foundations.zh-CN.md)负责共享原则与可复用 token；[样式设置面板表现](style-settings-panel.zh-CN.md)负责与 Drawer 共用的面板表面和控件。

## 界面与基础信息

- Home 保持壁纸清晰，不增加全屏暗化、染色、Scrim、玻璃表面或模糊。前景文字和单色图形使用共享 `primaryTextColor`，并可以使用一套固定、跟随字形的深色投影；准确投影数值需要在作者设备上校准，当前为 `To be decided`。
- Home 在 `safeDrawing` 内使用统一 `8dp` 内容 padding；相邻可见模块使用 `8dp` 间距。
- 基础信息模块不增加 padding。时间与日期行在已 padding 边界内使用 `8dp` 起止 margin，使行边界距安全边缘 `16dp`。时间行增加 `8dp` 顶部 margin，最终顶部距离为 `16dp`。日期文字再增加 `8dp` 起始 inset，距安全起始边缘 `24dp`，完整行目标仍位于 `16dp` 边界。
- 时间行至少高 `64dp`，使用 `57sp/64sp` 粗体 display 文字；日期行高 `48dp`，使用正常字重的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`。
- 收藏主列表及模块不在 Home 内容 padding 之外增加外部 padding。
- 最新可靠状态为禁用的收藏在两种模块中都继续使用普通测量几何，但应用图标与名称使用共享 `38%` 不可用透明度。应用级移除控件和移动反馈保持普通透明度，因为这些编辑操作仍然可用。

## 纵向收藏模块

- 模块使用完整的已 padding 内容宽度。大、中、小条目几何及名称右置／下置排列使用 Drawer 应用条目表现的适用数值。
- 每行一个且名称右置时沿用既有 Home 列表几何：大尺寸使用 `48dp` 图标与 `64dp` 项目高度；中尺寸使用 `40dp` 与 `56dp`；小尺寸使用 `32dp` 与 `48dp`。大、中、小名称分别使用正常字重的共享 `largeAppNameFontSize`、`primaryTextFontSize` 与 `secondaryTextFontSize`，配合各自共享行高和 `primaryTextColor`；三者均沿用 Drawer 的单行省略规则。
- 每种尺寸在名称右置时允许每行一至两个，在名称下置时允许每行一至四个。多列单元格准确几何复用 Drawer 的适用表现值；步进控件使用共享样式设置面板几何，在一和适用上限处使用既有启用／禁用表现，并在名称位置变化的同一帧更新：当前为二时从右置切换到下置会启用加号，当前为三或四时从下置切换到右置会显示二并禁用加号。
- 普通模式模块不使用模块级标题栏。样式设置面板收起时，应用级编辑只增加一个移除控件，不显示应用排序拖动柄，也不预留拖动柄空间；完整条目中移除目标以外的区域均作为长按移动目标。

## 横向收藏织带

- 织带全宽、单行、高 `56dp`，不设置容器 padding。多个织带或相邻模块使用共享 `8dp` 模块间距。
- 每项使用 `8dp` 起始 inset、`40dp` 图标、`8dp` 图标名称间距、一行最多测量至 `64dp` 的正常字重 `primaryTextFontSize` 名称及 `8dp` 末端 inset。名称使用对应共享行高和 `primaryTextColor`。总宽度按内容测量，最大 `128dp`；长名称尾部省略。项目间距为 `8dp`。
- 每项背景使用 `6%` 透明度的 `primaryTextColor`，`1dp` 边框使用 `12%`，圆角为 `12dp`；按压 Ripple 裁切到同一轮廓。

## 新增收藏入口

- 主列表的两个新增收藏入口在最后一个模块之后构成一行，该行上方使用共享 `8dp` 模块间距。两者等分已 padding 的内容宽度，中间间距 `8dp`，高度至少 `48dp`。
- 模块末尾新增收藏入口占据其模块最后一个应用之后的下一个条目位置。在纵向模块中使用该模块当前尺寸、名称位置、每行数量对应的单元格几何及适用的图标名称间距；在织带中使用织带条目几何。其图标槽位因此与所属模块的应用图标槽位一致：大／中／小纵向模块分别为 `48dp`、`40dp`、`32dp`，织带为 `40dp`；槽位内部始终居中显示共享 `24dp x 24dp` 加号图标。文案跟随所属模块的名称右置或名称下置排列，不强制使用同一种水平排列。两种情况都不在模块自身排列之外增加独立行高或容器 padding。
- 每个新增收藏入口使用织带条目的表面处理：`6%` 透明度的 `primaryTextColor` 背景、`12%` 的 `1dp` 边框和 `12dp` 圆角。按压 Ripple 裁切到同一轮廓。入口不增加壁纸暗化、染色、Scrim 或模糊。
- 主列表中的每个新增收藏入口把共享 `24dp x 24dp` 功能图标尺寸的加号图形（使用 `primaryTextColor`）与其本地化文案组合为一个单元：整体水平居中，图标与文案间距 `8dp`，文案使用正常字重的共享 `primaryTextFontSize`、对应共享行高和 `primaryTextColor`。模块末尾入口则复用上文规定的所属模块图标槽位、名称位置、间距、字号、行高与文案几何。所有文案保持单行并使用尾部省略；加号字符不属于本地化字符串。
- 独占保存尚未确定时，新增收藏入口使用共享 `38%` 禁用透明度，不增加额外 Loading 或进度指示器。
- 正在移动的应用悬停于有效主列表新增收藏入口时，该入口显示与已选模块相同的强调：完整 `2dp` `primaryTextColor` 边框、`12dp` 圆角，完全绘制在其边界以内，不增加填充或染色，也不改变其测量与周围间距。该落点强调在本次松手中替代插入线，二者永不同时出现，使目标落点与边界插入保持可区分。

## 编辑坞与样式设置面板

- 编辑坞固定在 `safeDrawing` 内的安全内容底部；无论样式设置面板收起或展开，高度始终准确为 `32dp`。系统底部安全 inset 不计入该高度。面板收起时，收藏主列表视口直接结束于编辑坞，两者之间间距为 `0dp`。
- 编辑坞不设置整体水平 padding。非交互提示文案占据扣除入口热区后的物理左侧区域，并在该区域内使用 `8dp` 起止 padding。文字垂直居中，保持完整单行且不使用省略号，并使用中等字重的共享 `secondaryTextFontSize`、对应行高和 `primaryTextColor`。
- 物理右侧的向上或向下入口使用 `48dp x 32dp` 热区，贴合编辑坞顶部、末端和底部边缘。可见方向图形使用共享 `24dp x 24dp` 功能图标尺寸和 `primaryTextColor`；准确 drawable 资源在实现时选择。作者接受该编辑坞专用目标作为共享 `48dp` 最小目标高度的例外。
- 展开面板把共享[样式设置面板](style-settings-panel.zh-CN.md)作为 Home 布局中的内嵌区域承载。它使用共享水平外边距、圆角表面、边缘阴影、设置行几何，以及适用的应用尺寸、名称位置和每行项目数量控件。Home 不增加底部外边距：面板紧贴始终可见的编辑坞上方，间距为 `0dp`。它保持非模态、不使用 Scrim，并位于收藏主列表视口之外。
- 面板展开时，基础信息区不参与布局。面板根据当前内容自然测量高度，不使用固定高度；它只能在可用安全布局内增长，不得覆盖收藏主列表或编辑坞。主列表视口至少保留 `112dp`；面板最大高度因此是为固定 `32dp` 编辑坞与该最小视口预留空间后剩余的安全内容高度。超过该面板高度的内容在面板内部滚动。内容驱动的高度变化使用共享短时长属性动画 token，并保留主列表的逻辑滚动位置。
- 模块不显示独立模块排序拖动柄，也不为拖动柄预留空间。样式设置面板展开时，每个可编辑且未选中的模块改为覆盖四个 `secondaryTextColor` 非交互圆角标记。每个标记形成一个弧形角，两条边各长 `16dp`、描边 `2dp`、向内缩进 `4dp`、弧度半径 `8dp`。这些标记提示完整模块表面支持选择与长按移动，不定义更小的触控目标，也不改变模块普通测量。等待长按识别期间不改变标记；独占编辑保存未完成时，标记使用共享 `38%` 禁用透明度，且不得暗示可以开始另一次移动。
- 展开的选择层用完整 `2dp` `primaryTextColor` 边框和 `12dp` 圆角替换已选模块的四角标记。边框完全绘制在模块边界以内，不增加填充或染色，也不改变模块测量或模块间距。独占编辑保存未完成时使用共享 `38%` 禁用透明度。模块可编辑、当前选中、抬起移动、插入位置及变更不可用因此保持可区分；选择层不能暴露应用级按压或拖动反馈。与其他 Home 前景处理共用的对比度投影仍须通过作者设备校准。
- 面板不显示模块类型行，也不为自定义模块名称预留视觉空间。未选择模块时，以一个不可交互的共享只读行显示契约规定的选择提示；选中纵向模块时直接从适用控件开始；选中织带时，以一个不可交互的共享只读行显示契约规定的固定样式说明，不渲染禁用样式控件。两个信息行均使用共享 `56dp` 行几何、中等字重的共享 `secondaryTextFontSize` 及其行高，并使用 `primaryTextColor`。面板既不提供新增操作，也不提供删除完整模块的控件。
- 应用移除控件使用纯错误红色 `20dp x 20dp` 圆形背景与白色 X；可见圆形同时就是作者接受的 `20dp x 20dp` 交互目标，并且必须保持在所属条目内。名称右置时，图标距条目物理左侧和顶部各 `8dp`，移除圆形贴合这两条条目边缘，使其与图标左上角形成 `12dp x 12dp` 覆盖；织带使用相同几何。名称下置时，图标与名称整体继续居中，移除圆形相对该图标左上角向左和向上各偏移 `8dp`，同样形成 `12dp x 12dp` 覆盖。

## 拖动与溢出反馈

- 织带溢出可以沿用向内 `48dp` 的 `primaryTextColor` 渐变，从透明上升至最多 `8%`，且不改变几何或输入归属。
- 模块移动在长按识别时冻结来源模块完整渲染结果的视觉快照。抬起拖影保留初始触控点相对位置，不保留源占位，保持完全不透明，即不透明度为 `100%`，缩放保持 `1.0`，并且在本次手势期间不实时更新。其余模块补齐源空缺但不改变宽度。拖影只增加 `12dp` elevation 风格阴影表达抬起状态。
- 每个移动候选只在已经解析的顺序边界显示一条不参与布局的 `2dp` `primaryTextColor` 插入线。模块移动在相邻模块的交界处显示横跨模块可用宽度的横线。单列纵向应用排列在候选条目顶部或底部边缘显示横跨条目可用宽度的横线；多列同一行或织带在候选条目物理左侧或右侧边缘显示横跨条目测量高度的竖线。换行边界只使用当前已经解析的“之前”或“之后”候选所属边缘，不得在两行同时重复表达同一个语义边界。插入线覆盖在内容上方，不预留空间，也不推动任何条目。
- 模块移动与应用移动使用相同且由资源定义的边缘自动滚动数值。每个适用的起始／末端或顶部／底部边缘感应区为 `48dp`；视口对应轴向尺寸小于 `96dp` 时，每侧感应区上限为该尺寸的一半。在同一有效感应区内连续停留 `120ms` 后启动滚动；随后速度从感应区内侧边界的 `0dp/s` 线性增加到视口外侧边缘准确的 `180dp/s`。
- 应用移动在来源条目的测量尺寸上保留一个源占位。占位不填充颜色，使用 `12%` 透明度的 `primaryTextColor` `1dp` 边框，并沿用来源条目的既有形状。抬起拖影保持来源表现、`100%` 不透明度和 `1.0` 缩放，直到有效跨模块松手成功保存，并只增加与模块移动相同的 `12dp` elevation 风格阴影。目标只使用上文定义的插入线表达候选，不执行临时完整列表重排，也不增加完整候选模块高亮。
- 移动指针位于有效边缘自动滚动感应区时，对应边缘显示一个向内 `48dp` 的方向性渐变，从透明上升到外侧边缘最多 `8%` 的 `primaryTextColor`。该反馈不参与布局；它在启动延迟期间出现，在该方向请求仍符合条件或已经活动时保留，并在条件失效时立即消失。它不替代插入线，也不增加触觉。
