# Home 表现规范

> 英文公共语义源：[home.md](home.md)。

## 职责

本文档负责 Home 精确布局、字体、组件几何与视觉状态。[Home 行为](../surfaces/home.zh-CN.md)负责状态和操作结果；[设计基础](../design-foundations.zh-CN.md)负责共享原则与可复用 token。

## 界面与基础信息

- Home 保持壁纸清晰，不增加全屏暗化、染色、Scrim、玻璃表面或模糊。前景文字和单色图形使用共享 `primaryTextColor`，并可以使用一套固定、跟随字形的深色投影；准确投影数值需要在作者设备上校准，当前为 `To be decided`。
- Home 在 `safeDrawing` 内使用统一 `8dp` 内容 padding；相邻可见模块使用 `8dp` 间距。
- 基础信息模块不增加 padding。时间与日期行在已 padding 边界内使用 `8dp` 起止 margin，使行边界距安全边缘 `16dp`。时间行增加 `8dp` 顶部 margin，最终顶部距离为 `16dp`。日期文字再增加 `8dp` 起始 inset，距安全起始边缘 `24dp`，完整行目标仍位于 `16dp` 边界。
- 时间行至少高 `64dp`，使用 `57sp/64sp` 粗体 display 文字；日期行高 `48dp`，使用正常字重的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`。
- 收藏主列表及模块不在 Home 内容 padding 之外增加外部 padding。

## 纵向收藏模块

- 模块使用完整的已 padding 内容宽度。大、中、小条目几何及名称右置／下置排列使用 Drawer 应用条目表现的适用数值。
- 每行一个且名称右置时沿用既有 Home 列表几何：大尺寸使用 `48dp` 图标与 `64dp` 项目高度；中尺寸使用 `40dp` 与 `56dp`；小尺寸使用 `32dp` 与 `48dp`。大、中、小名称分别使用正常字重的共享 `largeAppNameFontSize`、`primaryTextFontSize` 与 `secondaryTextFontSize`，配合各自共享行高和 `primaryTextColor`；三者均沿用 Drawer 的单行省略规则。
- 每种尺寸在名称右置时允许每行一至两个，在名称下置时允许每行一至四个。多列单元格准确几何复用 Drawer 的适用表现值；步进控件在一和适用上限处使用既有启用／禁用表现，并在名称位置变化的同一帧更新：当前为二时从右置切换到下置会启用加号，当前为三或四时从下置切换到右置会显示二并禁用加号。
- 普通模式模块不使用模块级标题栏。样式面板收起时，应用级编辑只增加一个移除控件，不显示应用排序拖动柄，也不预留拖动柄空间；完整条目中移除目标以外的区域均作为长按移动目标。

## 横向收藏织带

- 织带全宽、单行、高 `56dp`，不设置容器 padding。多个织带或相邻模块使用共享 `8dp` 模块间距。
- 每项使用 `8dp` 起始 inset、`40dp` 图标、`8dp` 图标名称间距、一行最多测量至 `64dp` 的正常字重 `primaryTextFontSize` 名称及 `8dp` 末端 inset。名称使用对应共享行高和 `primaryTextColor`。总宽度按内容测量，最大 `128dp`；长名称尾部省略。项目间距为 `8dp`。
- 每项背景使用 `6%` 透明度的 `primaryTextColor`，`1dp` 边框使用 `12%`，圆角为 `12dp`；按压 Ripple 裁切到同一轮廓。

## 编辑坞与样式面板

- 编辑坞固定在 `safeDrawing` 内的安全内容底部；无论样式面板收起或展开，高度始终准确为 `32dp`。系统底部安全 inset 不计入该高度。面板收起时，收藏主列表视口直接结束于编辑坞，两者之间间距为 `0dp`。
- 编辑坞不设置整体水平 padding。非交互提示文案占据扣除入口热区后的物理左侧区域，并在该区域内使用 `8dp` 起止 padding。文字垂直居中，保持完整单行且不使用省略号，并使用共享 `secondaryTextFontSize`、对应行高和 `primaryTextColor`；提示字重仍为 `To be decided`。
- 物理右侧的向上或向下入口使用 `48dp x 32dp` 热区，贴合编辑坞顶部、末端和底部边缘。可见方向图形使用共享 `24dp x 24dp` 功能图标尺寸和 `primaryTextColor`；准确 drawable 资源在实现时选择。作者接受该编辑坞专用目标作为共享 `48dp` 最小目标高度的例外。
- 展开面板是 Home 布局中的内嵌区域，沿用 Drawer 设置面板既有视觉层级，但保持非模态并位于收藏主列表视口之外。它紧贴始终可见的编辑坞上方，间距为 `0dp`，且不使用 Scrim。面板展开时，基础信息区不参与布局。面板准确高度、内部 padding、行几何、控件间距和滚动规则仍为 `To be decided`。
- 模块不显示独立模块排序拖动柄，也不为拖动柄预留空间。样式面板展开时，每个模块改为覆盖四个短且带圆角的角部编辑标记；这些非交互标记用于提示完整模块表面支持选择与长按移动，不定义更小的触控目标，也不改变模块普通测量。标记长度、描边宽度、内缩、圆角、颜色及各状态的准确数值仍为 `To be decided`。
- 展开的选择层必须清晰表达选中状态并保留模块身份可读性。选中状态使用与四角编辑标记不同的完整边框或蒙层，使可编辑、当前选中、按压识别、抬起移动和禁用状态不由同一视觉表达；不能暴露应用级按压或拖动反馈。选中与禁用状态的准确数值仍为 `To be decided`。
- 只读模块类型行位于适用控件之前，不为自定义模块名称预留视觉空间。
- 应用移除控件使用纯错误红色 `20dp x 20dp` 圆形背景与白色 X；可见圆形同时就是作者接受的 `20dp x 20dp` 交互目标，并且必须保持在所属条目内。名称右置时，图标距条目物理左侧和顶部各 `8dp`，移除圆形贴合这两条条目边缘，使其与图标左上角形成 `12dp x 12dp` 覆盖；织带使用相同几何。名称下置时，图标与名称整体继续居中，移除圆形相对该图标左上角向左和向上各偏移 `8dp`，同样形成 `12dp x 12dp` 覆盖。面板中的模块级删除几何遵循面板控件体系，准确值仍为 `To be decided`。

## 拖动与溢出反馈

- 织带溢出可以沿用向内 `48dp` 的 `primaryTextColor` 渐变，从透明上升至最多 `8%`，且不改变几何或输入归属。
- 模块移动使用保留初始触控点相对位置的完整抬起拖影，不保留源占位，并在候选边界显示一条插入线；其余模块补齐源空缺但不改变宽度。抬起拖影、插入线及任何可见边缘反馈的准确数值仍为 `To be decided`。
- 模块移动与应用移动使用相同且由资源定义的边缘自动滚动数值。每个适用的起始／末端或顶部／底部边缘感应区为 `48dp`；视口对应轴向尺寸小于 `96dp` 时，每侧感应区上限为该尺寸的一半。在同一有效感应区内连续停留 `120ms` 后启动滚动；随后速度从感应区内侧边界的 `0dp/s` 线性增加到视口外侧边缘准确的 `180dp/s`。
- 应用移动在来源条目的测量尺寸上保留一个源占位。抬起拖影保持来源表现，直到有效跨模块松手成功保存；目标只显示一处插入反馈，不执行临时完整列表重排。占位、拖影、候选模块强调和插入反馈的准确表现值仍为 `To be decided`，由后续 Home 编辑反馈表现工作确定。
