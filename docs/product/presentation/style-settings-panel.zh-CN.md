# 样式设置面板表现规范

> 英文公共语义源：[style-settings-panel.md](style-settings-panel.md)。

## 职责

本文是 Drawer 与 Home 样式设置面板共用视觉表面、设置行、选择器、步进控件和应用尺寸控件的唯一表现来源。[Drawer 表现](drawer.zh-CN.md#显示设置)与 [Home 表现](home.zh-CN.md#编辑坞与样式设置面板)只负责各自宿主特有的位置、模态性、高度、内容和周围布局；对应行为规范继续负责状态与操作结果。

这项共享产品契约要求两处呈现为可观察的一致面板样式，但不规定源码类、框架抽象或实现组件边界。

## 共享面板表面

- 样式设置面板使用一套资源化的 `darkSurfaceBaseColor` 深色表面、准确 `12dp` 圆角和清晰边缘阴影。Drawer 与 Home 使用相同的表面颜色、圆角半径、水平外边距和阴影，不得按宿主替换为另一套视觉值。
- 面板表面不设置整体容器 padding。每个只读行或设置行占据面板完整内部宽度，准确高 `56dp`，使用起止各 `12dp` 的内容 inset，并使内部内容垂直居中。
- 共享面板表面本身不定义 Scrim、模态输入阻断、点击外部关闭、底部外边距、最大高度、内部滚动或与其他控件的衔接方式；这些规则由各宿主分别负责。

## 共享选择器与控件

- 紧凑双选项选择器使用 `148dp x 44dp` 深色圆角外框、浅色边框和 `2dp` 内部 padding，包含两个等宽的 `72dp x 40dp` 浅色填充、无边框圆角滑块。居中选项文字使用中等字重的共享 `secondaryTextFontSize` 及对应行高。
- 选择器滑块和文字颜色转换使用同一个平台或主题短时长属性动画 token，以约 `200ms` 作为参考时长，不硬编码时长。
- 设置标题保持固定；只有完整尾部控件区域溢出时，该区域才横向滚动。
- 减少与增加控件使用本地化文字，显示在约 `32dp x 32dp`、圆角 `4dp` 的可见背景上；每行项目数量使用约 `36dp x 32dp` 的可见背景。三个控件各自保留至少 `48dp x 48dp` 的交互目标；可见背景尺寸不决定命中几何。
- 应用尺寸选择器占据一个共享 `56dp` 设置行。大、中、小每个选项包含一个选择指示器、通用应用图标预览和本地化标签。预览尺寸为 `48dp`、`40dp` 和 `32dp`；指示器与图标间距为 `4dp`，图标与标签间距为 `8dp`，标题与控件区间距为 `16dp`。选项之间不额外增加独立 `16dp` 间距，并各自保留至少 `48dp x 48dp` 的目标。
- 启用、选中、禁用、焦点、Ripple、文字和图标表现遵循[设计基础](../design-foundations.zh-CN.md)。宿主可以省略不适用的设置行，但不得重新设计共享设置行，也不得在对应行为契约没有要求时显示禁用占位。
