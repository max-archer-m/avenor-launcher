# 应用操作面板表现规范

> 英文公共语义源：[app-action-sheet.md](app-action-sheet.md)。

## 职责

本文档负责应用操作面板的精确表现数值。[应用操作面板行为](../surfaces/app-action-sheet.zh-CN.md)负责内容可用性、顺序语义和操作结果。

## 几何

- 在当前竖屏手机范围内，Bottom Sheet 占满完整可用屏幕宽度并贴合底部边缘；起始侧和末端侧顶部圆角均为 `12dp`。面板高度随内容自然增长，不设置固定产品高度或独立最大值；最高只能增长到状态栏安全 inset 的下边界，不得绘制到受保护的系统界面区域。
- 面板容器的全局内容 padding 为 `0dp`，每个内部区域自行负责间距。内容超过可用高度时，只有应用快捷操作区纵向滚动；应用身份行和适用的 Home 启动器操作行保持可见。
- 顶部拖动柄为 `32dp x 4dp`，其上方和下方各使用 `12dp` 垂直 padding。
- 应用身份行至少高 `48dp`，使用 `16dp` 水平内容 inset。应用名称使用 Material 3 `titleLarge`，保持静态单行，必要时使用末尾省略；视觉省略不得截断完整无障碍名称。
- 应用信息使用共享 `24dp` 功能图标 token，并位于 `48dp x 48dp` 交互目标中。
- 浅色分割线使用 `16dp` 水平 inset。
- 每个可选应用快捷操作占据至少高 `48dp` 的全宽交互行，使用 `16dp` 水平内容 inset、`24dp` 图标和 `16dp` 图标名称间距。名称保持静态单行并使用末尾省略，完整无障碍名称继续可用。
- 仅 Home 展示的启动器操作区使用 `16dp` 垂直 padding，并由横跨完整面板宽度的五个等宽槽位组成。可见操作从物理左侧依次占用槽位；隐藏或未使用槽位在右侧继续保留相同宽度。每个可见槽位是一个完整交互目标，使用 `24dp` 图标、`4dp` 图标标签间距和静态单行末尾省略标签。该区域不固定总高度，只根据单行内容和系统字体缩放的需要自然增长。Drawer 不预留启动器操作几何。
- Clone 或 profile badge 使用 `12dp x 12dp` 可见区域，覆盖对齐 Bottom Sheet 的末端侧底角，不设置向外偏移、margin、独立行、排除区域或预留内容空间。当前几何不得实际遮挡关键文字或交互目标；未来内容变化若产生真实碰撞，应修正对应内容表现，不因此默认预留 badge 空间。
