# Drawer 表现规范

> 英文公共语义源：[drawer.md](drawer.md)。

## 职责

本文档负责 Drawer 精确布局、字体、组件几何和视觉状态数值。[Drawer 行为](../surfaces/drawer.zh-CN.md)负责应用清单、排序、状态、选择与操作结果；[导航](../navigation.zh-CN.md)负责转换阈值。

## 界面与应用内容

- Drawer 在状态栏安全 inset 下使用透明且高 `56dp` 的顶部应用栏。返回箭头使用 `24dp` 图形和 `48dp` 交互目标。
- 普通应用行至少高 `56dp`，使用可见 `40dp x 40dp` 应用图标。完整行仍是选择和长按目标。
- 名称位于图标右侧时，每项使用 `8dp` 起始 inset、`40dp` 图标、`16dp` 图标名称间距和 `8dp` 末端 inset。
- 名称位于图标下方时，`40dp` 图标和名称作为整体居中，间距为 `8dp`，文字区域水平 inset 至少为 `8dp`。
- 列之间不增加独立间距，并按所选行数平分可用应用内容宽度。名称使用正常字重 `16sp/24sp`、静态单行和尾部省略。

## 分组锚点与字母索引

- 分组锚点使用粗体 `16sp/24sp`。内联锚点位于分组上方；左侧锚点位于分组项目旁；两者均随列表内容滚动。
- 字母索引标签在固定 `20dp` 槽位中使用 `11sp` 中等字重文字。Settings 齿轮使用 `11dp` 图形并位于一个完整 `20dp` 槽位内。
- 最大 28 槽模型在排除适用 inset 和 Drawer padding 后需要 `560dp` 完整可用高度。低于该高度时索引独立滚动。
- 活动 token 气泡至少为 `64dp x 64dp`，显示 `32sp` 中等字重文字或对应 Settings 齿轮。
- 非交互 Drawer 错误图标使用共享 `40dp` 状态图标 token。

## 收藏多选

- 多选在每个应用图标前保留 `40dp` 起始区域。居中的 `24dp` 圆形在可用且未选择时使用 `1dp` Material `outline` 边框。
- 选择后以浅色前景角色填充圆形，并使用深色 `surface` 角色的 `14sp/20sp` 中等字重文字显示从一开始的顺序。已选行使用 `8%` 透明度的浅色前景角色。
- 已收藏且禁用的行保留空指示器，指示器、图标和名称使用共享禁用语义透明度。

## 显示设置

- 中尺寸分组锚点选择器使用 `148dp x 44dp` 外框，包含两个相等的 `72dp x 40dp` 动画滑块。
- 应用尺寸选择器占据 `56dp` 设置行。大、中、小每个选项包含一个选择指示器、通用图标预览和本地化标签。
- 预览尺寸为 `48dp`、`40dp` 和 `32dp`。指示器与图标间距为 `4dp`，图标与标签间距为 `8dp`，标题与控制区间距为 `16dp`。选项之间不额外增加独立 `16dp` 间距，并各自保留至少 `48dp x 48dp` 的目标。
