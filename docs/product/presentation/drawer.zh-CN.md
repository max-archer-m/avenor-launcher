# Drawer 表现规范

> 英文公共语义源：[drawer.md](drawer.md)。

## 职责

本文档负责 Drawer 精确布局、字体、组件几何和视觉状态数值。[Drawer 行为](../surfaces/drawer.zh-CN.md)负责应用清单、排序、状态、选择与操作结果；[导航](../navigation.zh-CN.md)负责转换阈值；[设计基础](../design-foundations.zh-CN.md)负责共享颜色与字号 token。

## 界面与应用内容

- Drawer 在状态栏安全 inset 下使用高 `56dp` 的顶部应用栏。该栏在当前选定的 Drawer 背景上保持视觉透明，不创建自身独立表面。返回箭头使用 `24dp` 图形和 `48dp` 交互目标。
- 在“中”应用尺寸下，名称位于右侧的普通应用行至少高 `56dp`，使用可见 `40dp x 40dp` 应用图标。完整项目仍是选择和长按目标。
- 名称位于图标右侧时，每项使用 `8dp` 起始 inset、`40dp` 图标、`16dp` 图标名称间距和 `8dp` 末端 inset。
- 名称位于图标下方时，`40dp` 图标和名称作为整体居中，间距为 `8dp`，文字区域水平 inset 至少为 `8dp`。
- 列之间不增加独立间距，并按所选每行项目数量平分可用应用内容宽度。“大”“中”“小”名称分别使用正常字重的共享 `largeAppNameFontSize`、`primaryTextFontSize` 与 `secondaryTextFontSize`，配合各自共享行高和 `primaryTextColor`。所有名称均使用静态单行和尾部省略。
- 所有应用尺寸下，名称位于右侧时支持一列或两个等宽列，名称位于图标下方时支持一至四个等宽列。步进控件到达边界后，减少与增加目标继续保留普通几何，但使用共享禁用表现并暴露 disabled 状态，不显示可操作 Ripple。名称位置变化时，控件在同一帧根据生效数量更新启用或禁用表现：以二切换到`下方`时启用加号，以三或四切换到`右侧`时显示二并禁用加号。
- “大”和“小”的准确应用行高、排列 inset，以及名称位于图标下方时的项目高度均为 `To be decided`。图标尺寸采用已经确认的“大／中／小” `48dp`、`40dp`、`32dp` 序列；不得按比例推导其他未确认数值。

## 背景模式与对比度

- `透明`在完整 Drawer 中保持壁纸清晰，不增加全界面染色、scrim、玻璃层或模糊。直接位于壁纸上的文字和单色前景图形使用 `primaryTextColor` 和一套固定、跟随字形或图形轮廓的深色投影；投影颜色、透明度、偏移和模糊半径的准确值需要通过作者设备与壁纸校准决定，当前为 `To be decided`。
- `磨砂玻璃`在平台跨窗口模糊可用时，对完整界面使用一套固定背景模糊，并叠加低透明度中性色玻璃染色。它不采样壁纸，也不根据列表位置、指针位置、搜索结果或局部明度改变模糊、染色或对比度。模糊半径、染色语义角色和透明度需要通过 Samsung Galaxy S23 Ultra 与 Google Pixel 8 校准决定，当前为 `To be decided`。
- 平台模糊不可用时，已选`磨砂玻璃`用更高不透明度的固定中性玻璃表面替代模糊。备用表面的准确语义角色和透明度为 `To be decided`；它必须保持内容对比度，但不得表现为 Error、警告、禁用设置或自动切换到`透明`。
- 背景模式只改变 Drawer 背景和适用的对比度处理；顶部应用栏、应用、锚点、搜索、AlphabetIndex、Settings、多选、模态层和交互几何均不改变。

## 搜索框与命中强调

- 顶部应用栏包含一个高 `40dp` 且相对屏幕独立居中的搜索框。普通返回和展示设置控件替换为搜索模式的左侧空白预留与右侧`取消`后，搜索框仍保持居中。两侧预留和搜索框可以根据安全宽度调整，但不得重叠或使搜索框偏离屏幕中心。
- 搜索框内部透明，圆角为 `20dp`。前置放大镜和条件式尾部 X 的可见图形均为 `20dp`；内部 start 与 end inset 为 `12dp`，图形与文字间距为 `8dp`。X 居中位于至少 `48dp x 48dp` 的交互目标中；虽然可见搜索框较矮，该目标仍须位于完整的 `56dp` 顶部应用栏交互区域内。
- 提示与查询文字使用正常字重的共享 `primaryTextFontSize` 及其行高。英文提示为`Search apps`，简体中文提示为`搜索应用`。提示颜色使用 `secondaryTextColor`，输入文字使用 `primaryTextColor`。
- 非搜索模式使用 `1dp` Material `outline` 边界；搜索模式使用共享短时长颜色／属性动画 token，将边界变为 `primaryTextColor` 的 `2dp` 高亮。搜索模式仍生效时，查询为空、键盘隐藏或文字焦点暂时丢失均不移除高亮边界。
- 物理右侧`取消`文字使用中等字重的共享 `secondaryTextFontSize`、对应行高和 `primaryTextColor`，交互目标至少高 `48dp` 且宽度足以容纳完整本地化标签。对应的物理左侧预留与右侧等宽，但不提供可见控件、交互、焦点或无障碍节点。
- 应用名称的命中片段使用 `primaryTextColor` 和中等字重；未命中文字保留适用的普通样式。强调不增加背景、下划线、独立 padding、单独语义节点或几何变化。
- 无匹配提示在可用应用区域居中，使用正常字重的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`，不显示错误图标、进度指示器或重试呈现。

## 分组锚点与字母索引

- 分组锚点使用粗体的共享 `primaryTextFontSize`、对应行高和 `primaryTextColor`。内联锚点占据 `32dp` 高的行，并使用 `56dp` start 内缩使文字与应用名称列对齐；左侧锚点位于分组项目旁。两者均随列表内容滚动。
- 字母索引标签在固定 `20dp` 槽位中使用 `11sp` 中等字重文字。Settings 齿轮使用 `11dp` 图形并位于一个完整 `20dp` 槽位内。
- 最大索引模型包含 28 个固定槽位。由 Drawer 行为契约负责最终可用高度阈值和滚动决定。
- 活动 token 气泡至少为 `64dp x 64dp`，显示 `32sp` 中等字重文字或对应 Settings 齿轮。
- 非交互 Drawer 错误图标使用共享 `40dp` 状态图标 token。

## 收藏多选

- 多选在每个应用图标前保留 `40dp` 起始区域。居中的 `24dp` 圆形在可用且未选择时使用 `1dp` Material `outline` 边框。
- 选择后以 `primaryTextColor` 填充圆形，并使用 `darkSurfaceBaseColor` 的中等字重共享 `secondaryTextFontSize` 及对应行高显示从一开始的顺序。已选行使用 `8%` 透明度的 `primaryTextColor`。
- 已收藏且禁用的行保留空指示器，指示器、图标和名称使用共享禁用语义透明度。

## 显示设置

- 面板可以作为从底部进入的紧凑自定义表面。它采用深色圆角表面、明确的左右与底部间距，以及清晰边缘阴影，不调暗露出的 Drawer 或系统背景。透明模态层仍阻止底层输入；阴影必须使面板与两层露出背景保持清晰分层。
- 在“中”应用尺寸样本下，每个紧凑“标题加控件”设置行至少高 `56dp`。
- 分组锚点选择器使用 `148dp x 44dp` 深色圆角外框、浅色边框和 `2dp` 内部 padding，包含两个等宽的 `72dp x 40dp` 浅色填充、无边框圆角滑块。居中选项文字使用中等字重的共享 `secondaryTextFontSize` 及对应行高。
- 选择器滑块和文字颜色转换使用同一个平台或主题短时长属性动画 token，以约 `200ms` 作为参考时长，不硬编码时长。
- 排列设置标题保持固定；只有完整尾部控件区域溢出时，该区域才横向滚动。
- `右侧／下方`选择器使用与分组锚点选择器相同的 `148dp x 44dp` 外框、`2dp` padding 和两个等宽 `72dp x 40dp` 滑块。
- 减少与增加控件使用本地化文字，显示在约 `32dp x 32dp`、圆角 `4dp` 的可见背景上；每行项目数量使用约 `36dp x 32dp` 的可见背景。三个控件各自保留至少 `48dp x 48dp` 的交互目标；可见背景尺寸不决定命中几何。
- 应用尺寸选择器占据 `56dp` 设置行。大、中、小每个选项包含一个选择指示器、通用图标预览和本地化标签。
- 预览尺寸为 `48dp`、`40dp` 和 `32dp`。指示器与图标间距为 `4dp`，图标与标签间距为 `8dp`，标题与控制区间距为 `16dp`。选项之间不额外增加独立 `16dp` 间距，并各自保留至少 `48dp x 48dp` 的目标。
- Drawer 背景行在一个两项单选控件中显示`透明`和`磨砂玻璃`；英文对应`Transparent`和`Frosted glass`。完整本地化标签不得换行或缩写，且分别保留至少 `48dp x 48dp` 的目标；准确控件宽度和内部几何为 `To be decided`，不得强制套用现有更窄的两项选择器外框。
