# Avenor Launcher

> 英文语义源：[README.md](README.md)。

Avenor Launcher 是一个克制且有明确意图的 Android 主屏幕启动器，旨在帮助用户以尽可能少的干扰，找到所需应用和设备信息。

## 当前状态

项目处于规划阶段。产品范围、平台支持、发行要求、架构以及构建与验证基线仍在定义中。

## 产品方向

Avenor Launcher 的目标是作为 Android 设备的默认主屏幕应用。产品首先服务于作者的日常需求，未来可能通过英文和简体中文体验服务更广泛的全球用户。

产品优先考虑直接访问、克制的默认体验、用户控制权和重视隐私的设计。广告、推荐流及以提高参与时长为目标的模式不在已确认的产品边界内。

已确认的产品意图、边界和待解决范围见[项目概览](overview.zh-CN.md)，其[英文语义源](overview.md)亦可查阅。
